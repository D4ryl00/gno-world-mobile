# P3-M1 — Bubble Rumble dapp: session + game loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Expo app (iOS + Android) that obtains a dapp-held gno session key (GnoConnect `connect` with the dapp's key to gnokey-mobile, or the built-in desktop `gnokey` fallback) and plays Bubble Rumble with it: pools, boop (flag, clock boost, shot), claim, cancel, withdraw, create pool, teams, referral links, presence and the US gate.

**Architecture:** Pure TypeScript modules (game math, realm JSON parsing, GnoConnect links, gnokey commands, session state machine, off-chain HTTP) depend on a small `ChainApi` interface that gnonative's `GnoNativeApi` satisfies; the React layer (expo-router screens) gets them from one `AppServices` context. Everything chain-side goes through gnonative (keys in its Go keybase, session signing, `Render` JSON). An end-to-end suite drives the same modules against gnodev through gnonative's `goserver`.

**Tech Stack:** Expo SDK 57 (`create-expo-app@latest`), expo-router, TypeScript, zustand 5, `@gnolang/gnonative` (local tarball from P1), expo-secure-store, @react-native-async-storage/async-storage, expo-crypto, expo-clipboard, react-native-svg + react-native-qrcode-svg, bech32, jest-expo.

**Spec:** `docs/superpowers/specs/2026-10-01-bubblerumble-mobile-design.md` (§5, jalon M1) and `gnoconnect-session.md` (repo root).

## Review Focus

- A pool name the realm escaped with Go's `strconv.Quote` (`\x..` for invalid UTF-8, `\U........` for non-printable astral runes) makes `JSON.parse` throw: the list must still load (pinned in Task 4).
- A wallet reply whose `state` matches no pending request (forged, stale, or duplicated callback) must be ignored and never activate a session (pinned in Task 9).
- A wallet that answers `connect` without a session for the dapp's key (today's gnokey-mobile, which only knows the identity-only `connect`) must lead to the desktop fallback with the master address it returned, never to an active session (pinned in Task 9).
- The app is killed while the user is at the computer running the command: on relaunch the pending request, its key and its phase come back and polling resumes (pinned in Task 9).
- The user switches network (mainnet ↔ gnodev) with an active session: the session belongs to the chain it was created on and must not be used to sign on the other one (pinned in Task 9 and Task 6).
- The off-chain server is down or slow: presence fails quietly, play stays open, nothing blocks the game (pinned in Task 10).

`src/utils/gnot.ts`:

```ts
export const UGNOT_PER_GNOT = 1_000_000;

/** 1450000 → "1.45 GNOT" (the site's format). */
export function gnot(ugnot: number): string {
  const n = Math.trunc(Number(ugnot));
  const a = Math.abs(n);
  const whole = Math.floor(a / UGNOT_PER_GNOT);
  const frac = String(a % UGNOT_PER_GNOT).padStart(6, '0').replace(/0+$/, '');
  return `${n < 0 ? '-' : ''}${frac ? `${whole}.${frac}` : whole} GNOT`;
}

/** "1.5" → 1500000. Throws on more than 6 decimals or anything not a number. */
export function toUgnot(input: string): number {
  const s = String(input).trim();
  if (!s) return 0;
  const m = /^(\d*)(?:\.(\d{0,6}))?$/.exec(s);
  if (!m || (!m[1] && !m[2])) throw new Error('amount must be a number with up to 6 decimals');
  return Number((m[1] || '0') + (m[2] || '').padEnd(6, '0'));
}

const UNIT = { s: 1, m: 60, h: 3600, d: 86400 } as const;

/** "90m" → 5400, "2.5d" → 216000: the site's window syntax. */
export function parseDuration(input: string): number {
  const m = /^(\d+(?:\.\d+)?)\s*([smhd])$/.exec(String(input).trim().toLowerCase());
  if (!m) throw new Error('a number and s, m, h or d — 90m, 3h, 2.5d');
  return Math.round(parseFloat(m[1]) * UNIT[m[2] as keyof typeof UNIT]);
}

/** 34587 → "9h 36m 27s": at most three units, from the first non-zero one. */
export function humanDuration(seconds: number): string {
  let s = Math.max(0, Math.floor(seconds));
  const d = Math.floor(s / 86400);
  s -= d * 86400;
  const h = Math.floor(s / 3600);
  s -= h * 3600;
  const m = Math.floor(s / 60);
  s -= m * 60;
  const parts: [number, string][] = [[d, 'd'], [h, 'h'], [m, 'm'], [s, 's']];
  const first = parts.findIndex(([v]) => v > 0);
  if (first === -1) return '0s';
  return parts.slice(first, first + 3).map(([v, u]) => `${v}${u}`).join(' ');
}
```

`src/game/pricing.ts`:

```ts
export const MIN_CLOCK = 300;
export const MAX_BOOST = 10;
export const BOOSTS = [1, 2, 4, 10] as const;
export const BOOST_LABELS = ['100%', '50%', '25%', '10%'] as const;

/** The Nth boop's price: Price(base, bids) = ceil(base·√(bids+1)). */
export const price = (base: number, bids: number) => Math.ceil(base * Math.sqrt(bids + 1));

/** ClockFor: the window divided by the multiple paid, within [max(window/10, 5 min), window]. */
export function clockFor(window: number, priceU: number, sent: number): number {
  let c = Math.trunc((window * priceU) / sent);
  if (c < Math.trunc(window / MAX_BOOST)) c = Math.trunc(window / MAX_BOOST);
  if (c < MIN_CLOCK) c = MIN_CLOCK;
  if (c > window) c = window;
  return c;
}

const POOL_FUNCS = new Set(['Bid', 'Claim', 'Cancel']);

/** The site's gas table; fee in ugnot. */
export function gasFor(func: string, pool?: { bids: number; shots: number }) {
  if (pool && POOL_FUNCS.has(func)) {
    const wanted = Math.min(1e8, 3e7 + 3e5 * pool.bids + 1e6 * pool.shots);
    return { wanted, fee: wanted / 1000 };
  }
  return { wanted: 3e7, fee: 3e4 };
}
```

```ts
export const shotTip = (p: ShotInputs) => (p.version >= 4 ? p.revealTip || 20000 : 0);

/** The site's takeFor: what a pop would pay this player now, after a bid of `bid` and a shot of `shot`. */
export function takeFor(p: ShotInputs, bid: number, shot: number): number {
  const a =
    p.pot +
    Math.floor(bid * (p.version >= 5 ? 0.5 : 0.55)) +
    (p.hasRef ? 0 : Math.floor(0.1 * bid)) +
    (p.bids === 0 ? Math.floor(0.3 * bid) : 0) +
    shot -
    shotTip(p);
  const others = p.roster.filter((m) => m.addr !== p.me);
  if (!others.length) return a;
  const mine = p.roster.find((m) => m.addr === p.me);
  const s = p.bids > 0 ? p.liveBps : 10000;
  const i = a - Math.floor(0.35 * a);
  const l = i - Math.floor((i * s) / 10000);
  const c = p.roster.reduce((t, m) => t + m.paid, 0) + bid;
  const d = c - ((mine ? mine.paid : 0) + bid);
  return a - Math.floor((l * d) / Math.max(1, c));
}

const shotPrize = (p: ShotInputs, bid: number, shot: number) =>
  p.version >= 4 ? takeFor(p, bid, shot) : Math.min(p.pot, 1e7);

/** The shot that buys `bps` (25, 50 or 100) basis points with a bid of `bid`. */
export function shotFor(p: ShotInputs, bps: number, bid: number): number {
  if (p.version < 4) return Math.ceil((bps * shotPrize(p, bid, 0)) / SHOT_FAIR);
  let a = 0;
  for (let n = 0; n < 3; n++) a = Math.ceil((bps * shotPrize(p, bid, a)) / SHOT_FAIR) + shotTip(p);
  return Math.max(a, p.minShot || 100000);
}

/** Chance in basis points that `shot` pops the bubble. */
export function oddsBps(p: ShotInputs, bid: number, shot: number): number {
  if (shot <= 0) return 0;
  return Math.min(
    SHOT_MAX_BPS,
    Math.floor((SHOT_FAIR * Math.max(0, shot - shotTip(p))) / Math.max(1, shotPrize(p, bid, shot))),
  );
}

/** Why shots cannot be sold right now, or "" when they can (v4+ only). */
export function shotPause(p: ShotInputs, info: ShotRealmInfo): string {
  if (p.version < 4) return '';
  if (!info.shotsOn) return 'shots are off';
  if (!info.commitsFree) return 'the keeper has no commitments left — shots are paused, back soon';
  if (!info.keeperSeen || info.now - info.keeperSeen > (info.keeperFresh || 300))
    return 'the keeper has not been seen for a while — shots are paused';
  if (p.bids > 0 && p.liveBps < (info.liveFloor || 2500))
    return "the winner's share has slid under a quarter — no more shots on this bubble";
  return '';
}
```

```ts
  ...VERSIONS.map((v) => `vm/exec:${REALMS[v]}`),
  `vm/exec:${BUBBLE_REALM}`,
  `vm/exec:${WBUBBLE_REALM}`,

export function parsePoolKey(key: string): { version: Version; id: number } | null {
  const m = /^v([1-5])-(\d+)$/.exec(key);
  return m ? { version: Number(m[1]) as Version, id: Number(m[2]) } : null;
}

  if (v === 2) return [String(id), ref, flag];
  return [String(id)];
}
```

```ts
import { poolKey, type Version } from './realms';

export interface BidEntry { n: number; bidder: string; flag: string; price: number; shot: number; clock: number; pot: number; at: number }
export interface Member { addr: string; flag: string; paid: number; earned: number }
export interface ShotEntry { n: number; bidder: string; paid: number; take: number; bps: number; revealAt: number; revealBy: number; resolved: boolean; hit: boolean; void: boolean }

export interface Pool {
  key: string; version: Version; id: number; name: string; creator: string;
  window: number; life: number; basePrice: number; seed: number; pot: number;
  bids: number; nextPrice: number; lastBidder: string; lastBidAt: number; firstBidAt: number;
  deadline: number; lastDay: number; liveBps: number; clock: number; createdAt: number;
  over: boolean; popped: boolean; paid: boolean; cancelled: boolean;
  bidders: number; shots: number; misses: number; pending: number;
  flag: string; teams: Record<string, number>;
  creatorPaid: number; divPaid: number; refPaid: number; treasuryPaid: number;
  winnerPaid: number; teamPaid: number; sharedPaid: number;
  history: BidEntry[]; roster: Member[]; shotlog: ShotEntry[];
}

export interface RealmInfo {
  version: Version; now: number; shotsOn: boolean; keeperSeen: number; commitsFree: number;
  split: Record<string, number>; pools: Pool[];
}

export interface Me {
  addr: string; referrer: string; recruits: number; flag: string; bids: number; paid: number;
  divEarned: number; refEarned: number; won: number; shots: number; hits: number; owed: number; withdrawn: number;
}

export type Teams = Record<string, { paid: number; won: number; players: number }>;

type Obj = Record<string, unknown>;
const num = (v: unknown, d = 0) => (typeof v === 'number' && Number.isFinite(v) ? v : d);
const str = (v: unknown) => (typeof v === 'string' ? v : '');
const bool = (v: unknown) => v === true;
const obj = (v: unknown): Obj => (v && typeof v === 'object' && !Array.isArray(v) ? (v as Obj) : {});
const arr = (v: unknown): Obj[] => (Array.isArray(v) ? v.map(obj) : []);
const numMap = (v: unknown) =>
  Object.fromEntries(Object.entries(obj(v)).filter(([, n]) => typeof n === 'number')) as Record<string, number>;

const hex = (h: string) => parseInt(h, 16);
const u4 = (n: number) => '\\u' + n.toString(16).padStart(4, '0');

/**
 * JSON.parse that also accepts the escapes Go's strconv.Quote emits and JSON lacks:
 * \xHH (a raw byte, kept as U+00HH) and \UHHHHHHHH (an astral rune, rewritten as a surrogate pair).
 */
export function parseJSONLoose(raw: string): unknown {
  let out = '';
  for (let i = 0; i < raw.length; i++) {
    const c = raw[i];
    if (c !== '\\') {
      out += c;
      continue;
    }
    const n = raw[i + 1];
    if (n === 'x' && /^[0-9a-fA-F]{2}$/.test(raw.slice(i + 2, i + 4))) {
      out += u4(hex(raw.slice(i + 2, i + 4)));
      i += 3;
    } else if (n === 'U' && /^[0-9a-fA-F]{8}$/.test(raw.slice(i + 2, i + 10))) {
      const cp = hex(raw.slice(i + 2, i + 10)) - 0x10000;
      out += cp < 0 ? u4(cp + 0x10000) : u4(0xd800 + (cp >> 10)) + u4(0xdc00 + (cp & 0x3ff));
      i += 9;
    } else {
      out += c + (n ?? '');
      i += 1;
    }
  }
  return JSON.parse(out);
}

function load(raw: string, what: string): Obj {
  try {
    return obj(parseJSONLoose(raw));
  } catch (e) {
    throw new Error(`${what}: unreadable answer (${(e as Error).message})`);
  }
}

function toPool(o: Obj, v: Version): Pool {
  const lastBidAt = num(o.lastBidAt);
  const clock = num(o.clock);
  return {
    key: poolKey(v, num(o.id)), version: v, id: num(o.id), name: str(o.name), creator: str(o.creator),
    window: num(o.window), life: num(o.life), basePrice: num(o.basePrice), seed: num(o.seed), pot: num(o.pot),
    bids: num(o.bids), nextPrice: num(o.nextPrice), lastBidder: str(o.lastBidder), lastBidAt,
    firstBidAt: num(o.firstBidAt),
    deadline: num(o.deadline, lastBidAt > 0 ? lastBidAt + clock : 0),
    lastDay: num(o.lastDay), liveBps: num(o.liveBps, 10000), clock, createdAt: num(o.createdAt),
    over: bool(o.over), popped: bool(o.popped), paid: bool(o.paid), cancelled: bool(o.cancelled),
    bidders: num(o.bidders), shots: num(o.shots), misses: num(o.misses), pending: num(o.pending),
    flag: str(o.flag), teams: numMap(o.teams),
    creatorPaid: num(o.creatorPaid), divPaid: num(o.divPaid), refPaid: num(o.refPaid),
    treasuryPaid: num(o.treasuryPaid), winnerPaid: num(o.winnerPaid), teamPaid: num(o.teamPaid),
    sharedPaid: num(o.sharedPaid),
    history: arr(o.history).map((h) => ({
      n: num(h.n), bidder: str(h.bidder), flag: str(h.flag), price: num(h.price), shot: num(h.shot),
      clock: num(h.clock), pot: num(h.pot), at: num(h.at),
    })),
    roster: arr(o.roster).map((m) => ({ addr: str(m.addr), flag: str(m.flag), paid: num(m.paid), earned: num(m.earned) })),
    shotlog: arr(o.shotlog).map((s) => ({
      n: num(s.n), bidder: str(s.bidder), paid: num(s.paid), take: num(s.take), bps: num(s.bps),
      revealAt: num(s.revealAt), revealBy: num(s.revealBy),
      resolved: bool(s.resolved), hit: bool(s.hit), void: bool(s.void),
    })),
  };
}

export function parseRealm(raw: string, v: Version): RealmInfo {
  const o = load(raw, `realm v${v}`);
  return {
    version: v, now: num(o.now), shotsOn: bool(o.shotsOn), keeperSeen: num(o.keeperSeen),
    commitsFree: num(o.commitsFree), split: numMap(o.split), pools: arr(o.pools).map((p) => toPool(p, v)),
  };
}

export const parsePool = (raw: string, v: Version): Pool => toPool(load(raw, `pool v${v}`), v);

export function parseMe(raw: string): Me {
  const o = load(raw, 'player');
  return {
    addr: str(o.addr), referrer: str(o.referrer), recruits: num(o.recruits), flag: str(o.flag),
    bids: num(o.bids), paid: num(o.paid), divEarned: num(o.divEarned), refEarned: num(o.refEarned),
    won: num(o.won), shots: num(o.shots), hits: num(o.hits), owed: num(o.owed), withdrawn: num(o.withdrawn),
  };
}

export function parseTeams(raw: string): Teams {
  const o = load(raw, 'teams');
  return Object.fromEntries(
    Object.entries(o).map(([cc, t]) => {
      const x = obj(t);
      return [cc, { paid: num(x.paid), won: num(x.won), players: num(x.players) }];
    }),
  );
}
```

```ts
import { bech32 } from 'bech32';

const LIMIT = 1023;

function decode(s: string, prefix: string): Uint8Array {
  const d = bech32.decode(s, LIMIT);
  if (d.prefix !== prefix) throw new Error(`expected a ${prefix}1… string, got ${d.prefix}1…`);
  return new Uint8Array(bech32.fromWords(d.words));
}
const encode = (prefix: string, b: Uint8Array) => bech32.encode(prefix, bech32.toWords(b), LIMIT);

export const decodeAddress = (s: string) => decode(s, 'g');
export const encodeAddress = (b: Uint8Array) => encode('g', b);
export const decodePubKey = (s: string) => decode(s, 'gpub');
export const encodePubKey = (b: Uint8Array) => encode('gpub', b);

export const bytesToHex = (b: Uint8Array) => Array.from(b, (x) => x.toString(16).padStart(2, '0')).join('');
```

```ts
export type ChainErrorKind =
  | 'budget' | 'expired' | 'unknown-session' | 'not-allowed' | 'funds'
  | 'realm' | 'network' | 'wrong-chain' | 'no-session' | 'other';

export class ChainError extends Error {
  constructor(public kind: ChainErrorKind, message: string, public raw?: unknown) {
    super(message);
    this.name = 'ChainError';
  }
}

const RULES: [RegExp, ChainErrorKind][] = [
  [/session spend limit (would be )?exceeded|session has no spend limit/i, 'budget'],
  [/session expired/i, 'expired'],
  [/unknown session|session not found/i, 'unknown-session'],
  [/not permitted by session AllowPaths/i, 'not-allowed'],
  [/insufficient (funds|coins)/i, 'funds'],
  [/ECONNREFUSED|unreachable|network request failed|failed to fetch|timed? ?out|unable to connect/i, 'network'],
];

const REALM_TEXT =
  /(pool is closed|pool was cancelled|send at least [^\n,]+(?:, got [^\n,]+)?|name must be [^\n]+?(?=\n|$)|name has control characters|window must be [^\n]+?(?=\n|$)|base price must be [^\n]+?(?=\n|$)|life must be [^\n]+?(?=\n|$)|shot must be [^\n]+?(?=\n|$)|must be a direct user call|nothing to (?:claim|withdraw)[^\n]*|only ugnot is accepted|bad pool id)/i;

export function classifyError(e: unknown): ChainError {
  if (e instanceof ChainError) return e;
  const msg = String((e as { message?: unknown })?.message ?? e);
  for (const [re, kind] of RULES) if (re.test(msg)) return new ChainError(kind, msg.split('\n')[0], e);
  const realm = REALM_TEXT.exec(msg);
  if (realm) return new ChainError('realm', realm[1].trim(), e);
  return new ChainError('other', msg.split('\n')[0], e);
}
```

```ts
import { gasFor } from '@/game/pricing';
import type { ActiveSession } from '@/session/types';
import { bytesToHex, decodeAddress } from '@/utils/bech32';

import type { ChainApi } from './api';
import { ChainError, classifyError } from './errors';
import { parseMe, parsePool, parseRealm, parseTeams, type Me, type Pool, type RealmInfo, type Teams } from './parse';
import { bidArgs, caps, REALMS, VERSIONS, type Version } from './realms';

export interface TxResult { hash: string; height: number }
export interface BidOptions { ref: string; flag: string; boost: number; shot: number }
export interface PoolForm { name: string; window: number; basePrice: number; life: number; seed: number }
export interface AllPools { pools: Pool[]; realms: Partial<Record<Version, RealmInfo>>; failed: Version[] }

export class GameClient {
  constructor(private api: ChainApi, private chainId: () => string) {}

  async realm(v: Version): Promise<RealmInfo> {
    return parseRealm(await this.api.render(REALMS[v], 'json'), v);
  }

  async allPools(): Promise<AllPools> {
    const res = await Promise.allSettled(VERSIONS.map((v) => this.realm(v)));
    const out: AllPools = { pools: [], realms: {}, failed: [] };
    res.forEach((r, i) => {
      const v = VERSIONS[i];
      if (r.status === 'fulfilled') {
        out.realms[v] = r.value;
        out.pools.push(...r.value.pools);
      } else out.failed.push(v);
    });
    return out;
  }

  async pool(v: Version, id: number): Promise<Pool> {
    if (caps(v).poolJson) return parsePool(await this.api.render(REALMS[v], `json/${id}`), v);
    const p = (await this.realm(v)).pools.find((x) => x.id === id);
    if (!p) throw new Error(`no pool v${v}-${id}`);
    return p;
  }

  async me(v: Version, addr: string): Promise<Me | null> {
    if (!caps(v).me) return null;
    return parseMe(await this.api.render(REALMS[v], `me/${addr}`));
  }

  async teams(): Promise<Teams> {
    return parseTeams(await this.api.render(REALMS[5], 'teams'));
  }

  bid(s: ActiveSession, p: Pool, o: BidOptions): Promise<TxResult> {
    const shot = caps(p.version).shots ? o.shot : 0;
    const sent = p.nextPrice * o.boost + shot;
    return this.exec(s, p.version, 'Bid', bidArgs(p.version, p.id, o.ref, o.flag, shot), sent, gasFor('Bid', p));
  }

  claim(s: ActiveSession, p: Pool) {
    return this.exec(s, p.version, 'Claim', [String(p.id)], 0, gasFor('Claim', p));
  }

  cancel(s: ActiveSession, p: Pool) {
    return this.exec(s, p.version, 'Cancel', [String(p.id)], 0, gasFor('Cancel', p));
  }

  async withdraw(s: ActiveSession, v: Version) {
    if (!caps(v).withdraw) throw new ChainError('other', `v${v} has no Withdraw: its payouts were sent directly`);
    return this.exec(s, v, 'Withdraw', [], 0, gasFor('Withdraw'));
  }

  createPool(s: ActiveSession, f: PoolForm) {
    const args = [f.name, String(f.window), String(f.basePrice), String(f.life)];
    return this.exec(s, 5, 'CreatePool', args, f.seed, gasFor('CreatePool'));
  }

  private async exec(
    s: ActiveSession, v: Version, fnc: string, args: string[], send: number, gas: { wanted: number; fee: number },
  ): Promise<TxResult> {
    if (s.chainId !== this.chainId())
      throw new ChainError('wrong-chain', `this session was made on ${s.chainId}; switch back or make one for ${this.chainId()}`);
    try {
      const stream = await this.api.call(
        REALMS[v], fnc, args, `${gas.fee}ugnot`, BigInt(gas.wanted), decodeAddress(s.address),
        send > 0 ? [{ denom: 'ugnot', amount: BigInt(send) }] : undefined,
      );
      let last: { hash: Uint8Array; height: bigint } | undefined;
      for await (const r of stream) last = r;
      return { hash: last ? bytesToHex(last.hash) : '', height: last ? Number(last.height) : 0 };
    } catch (e) {
      throw classifyError(e);
    }
  }
}
```

```ts
    if (r === undefined) throw new Error(`no render for ${pkg}:${args}`);
    return r;

  async call(pkg: string, fnc: string, args: string[], gasFee: string, gasWanted: bigint, signer: Uint8Array, send?: Coin[]) {
    if (this.failNextCall) {
      const e = this.failNextCall;
      this.failNextCall = null;
      throw e;
    }
    this.calls.push({ pkg, fnc, args, gasFee, gasWanted, signerHex: bytesToHex(signer), send });
    return (async function* () {
      yield { hash: new Uint8Array([0xab, 0xcd]), height: 7n };
    })();
  }
  async queryAccount(address: Uint8Array) {
    return { accountInfo: { coins: this.balances.get(bytesToHex(address)) ?? [] } };
  }
  async querySessionAccount(master: Uint8Array, session: Uint8Array) {
    const s = this.sessions.get(`${bytesToHex(master)}/${bytesToHex(session)}`);
    if (!s) throw new Error('session not found');
    return { accountInfo: s };
  }
  async generateRecoveryPhrase() {
    return `phrase-${++this.n}`;
  }
  async createAccount(name: string, _mnemonic: string, password: string) {
    const i = ++this.n;
    const address = new Uint8Array(20).fill(i);
    const pubKey = new Uint8Array(38).fill(i);
    this.keys.set(name, { address, pubKey, password });
    return { address, pubKey };
  }
  async activateAccount(name: string, master?: Uint8Array) {
    const prev = this.activated.get(name) ?? {};
    this.activated.set(name, { ...prev, master: master ? bytesToHex(master) : undefined });
    return { hasPassword: !!prev.password };
  }
  async setPassword(password: string, address: Uint8Array) {
    for (const [name, k] of this.keys)
      if (bytesToHex(k.address) === bytesToHex(address)) {
        if (k.password !== password) throw new Error('decryption failed');
        this.activated.set(name, { ...this.activated.get(name), password });
      }
  }
  async signBytes(address: Uint8Array, data: Uint8Array) {
    this.signed.push({ addressHex: bytesToHex(address), data: new TextDecoder().decode(data) });
    return { signature: new Uint8Array(64).fill(7), pubKey: new Uint8Array(38) };
  }
```

```ts
const A = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_';

/** RFC 4648 §5, no padding. */
export function base64url(b: Uint8Array): string {
  let out = '';
  let i = 0;
  for (; i + 2 < b.length; i += 3) {
    const n = (b[i] << 16) | (b[i + 1] << 8) | b[i + 2];
    out += A[(n >> 18) & 63] + A[(n >> 12) & 63] + A[(n >> 6) & 63] + A[n & 63];
  }
  const rem = b.length - i;
  if (rem === 1) {
    const n = b[i] << 16;
    out += A[(n >> 18) & 63] + A[(n >> 12) & 63];
  } else if (rem === 2) {
    const n = (b[i] << 16) | (b[i + 1] << 8);
    out += A[(n >> 18) & 63] + A[(n >> 12) & 63] + A[(n >> 6) & 63];
  }
  return out;
}
```

```ts
/** One random password protects every session key in gnonative's keybase; it lives in the secure store. */
export async function keybasePassword(store: SecretStore, randomHex: (bytes: number) => string): Promise<string> {
  const have = await store.get(PASSWORD_KEY);
  if (have) return have;
  const pw = randomHex(32);
  await store.set(PASSWORD_KEY, pw);
  return pw;
}

export async function createSessionKey(
  api: ChainApi, store: SecretStore, randomHex: (bytes: number) => string, now: () => number,

  const keyName = `br-session-${now()}`;
  const info = await api.createAccount(keyName, await api.generateRecoveryPhrase(), password);
  if (!info) throw new Error('gnonative did not create the key');
  return { keyName, address: encodeAddress(info.address), pubkey: encodePubKey(info.pubKey) };
}
```

`src/session/gnoconnect.ts`:

```ts
import { base64url } from '@/utils/base64url';

import type { Grant } from './types';

export const WALLET_SCHEME = 'land.gno.gnokey';
export const CALLBACK_URL = 'bubblerumble://session-callback';
/** `connect` with `pubkey` grants (with `old`, renews in one transaction); `disconnect` revokes. */
export type SessionHost = 'connect' | 'disconnect';

const enc = encodeURIComponent;

function splitLink(link: string): { host: string; query: string; fragment: string } {
  const afterScheme = link.slice(link.indexOf('://') + 3);
  const hash = afterScheme.indexOf('#');
  const noFrag = hash >= 0 ? afterScheme.slice(0, hash) : afterScheme;
  const q = noFrag.indexOf('?');
  const hostPath = q >= 0 ? noFrag.slice(0, q) : noFrag;
  return {
    host: hostPath.split('/')[0].toLowerCase(),
    query: q >= 0 ? noFrag.slice(q + 1) : '',
    fragment: hash >= 0 ? afterScheme.slice(hash + 1) : '',
  };
}

/** Strict RFC 3986 decoding: '+' stays a plus. */
function entries(qs: string): [string, string][] {
  return qs
    .split('&')
    .filter(Boolean)
    .map((part) => {
      const i = part.indexOf('=');
      const k = i >= 0 ? part.slice(0, i) : part;
      const v = i >= 0 ? part.slice(i + 1) : '';
      return [decodeURIComponent(k), decodeURIComponent(v)];
    });
}

/** The proof-of-possession payload (gnoconnect-session.md, "Proof of possession"). */
export function canonicalPayload(link: string): string {
  const { host, query } = splitLink(link);
  const kvs = entries(query).filter(([k]) => k !== 'sig' && k !== 'oldsig');
  for (const [k, v] of kvs) if (/[\u0000-\u001f\u007f]/.test(k + v)) throw new Error(`control character in ${k}`);
  kvs.sort(([ak, av], [bk, bv]) => (ak !== bk ? (ak < bk ? -1 : 1) : av < bv ? -1 : av > bv ? 1 : 0));
  return ['gnoconnect-session-v1', `host=${host}`, ...kvs.map(([k, v]) => `${k}=${v}`)].join('\n');
}

export interface SessionRequest {
  host: SessionHost;
  pubkey: string;
  old?: string;
  grant?: Grant;
  allow?: string[];
  chainid: string;
  rpc?: string;
  signer?: string;
  callback: string;
  state: string;
  iat: number;
}

export function buildSessionLink(r: SessionRequest): string {
  const p: [string, string][] = [['pubkey', r.pubkey]];
  if (r.old) p.push(['old', r.old]);
  for (const a of r.allow ?? []) p.push(['allow', a]);
  if (r.grant) {
    p.push(['spend', `${r.grant.spendPerPeriod}ugnot`], ['period', String(r.grant.period)], ['expires', String(r.grant.expires)]);
  }
  p.push(['chainid', r.chainid]);
  if (r.rpc) p.push(['rpc', r.rpc]);
  if (r.signer) p.push(['signer', r.signer]);
  p.push(['callback', r.callback], ['state', r.state], ['iat', String(r.iat)]);
  return `${WALLET_SCHEME}://${r.host}?${p.map(([k, v]) => `${k}=${enc(v)}`).join('&')}`;
}

type Signer = (data: Uint8Array) => Promise<Uint8Array>;

export async function signLink(link: string, sign: Signer, signOld?: Signer): Promise<string> {
  const data = new TextEncoder().encode(canonicalPayload(link));
  let out = `${link}&sig=${base64url(await sign(data))}`;
  if (signOld) out += `&oldsig=${base64url(await signOld(data))}`;
  return out;
}

export interface WalletReply {
  status: 'success' | 'cancelled' | 'error';
  code: string;
  state: string;
  address: string;
  session: string;
  expiresAt: number;
  allow: string[];
  spend: string;
  period: number;
  chainid: string;
  hash: string;
  /** the address of `old`, when this transaction revoked it */
  revoked: string;
}

export function parseReplyEntries(es: [string, string][]): WalletReply | null {
  const last = (k: string) => {
    for (let i = es.length - 1; i >= 0; i--) if (es[i][0] === k) return es[i][1];
    return '';
  };
  const status = last('status');
  if (status !== 'success' && status !== 'cancelled' && status !== 'error') return null;
  return {
    status, code: last('code'), state: last('state'), address: last('address'), session: last('session'),
    expiresAt: Number(last('expires_at')) || 0, allow: es.filter(([k]) => k === 'allow').map(([, v]) => v),
    spend: last('spend'), period: Number(last('period')) || 0, chainid: last('chainid'), hash: last('hash'),
    revoked: last('revoked'),
  };
}

export function parseReplyURL(url: string): WalletReply | null {
  const { query, fragment } = splitLink(url);
  return parseReplyEntries([...entries(query), ...entries(fragment)]);
}

/**
 * Whether the reply grants a session to the key at `keyAddress`. A wallet that does not know `pubkey` answers an
 * identity-only `connect`: no `session`, or its own delegated key there. That answer still carries the identity.
 */
export const grantsKey = (r: WalletReply, keyAddress: string) =>
  r.status === 'success' && r.session !== '' && r.session === keyAddress;
```

```ts
import type { Grant, SessionKey } from './types';

export interface CommandContext {
  chainId: string;
  remote: string;
  /** the identity's key name in the user's gnokey; YOUR_KEY by default, as on the site */
  keyName?: string;
  /** inserted before the key name (e.g. -home <dir> -insecure-password-stdin in tests) */
  extraFlags?: string[];
}

const q = (s: string) => (/^[A-Za-z0-9_@%+=:,./-]+$/.test(s) ? s : `'${s.replace(/'/g, `'\\''`)}'`);

export const expiresArg = (seconds: number) => (seconds % 86400 === 0 ? `${seconds / 86400}d` : `${seconds}s`);

function tail(ctx: CommandContext): string[] {
  return [
    '-gas-fee', '1000000ugnot', '-gas-wanted', '2000000', '-broadcast',
    '-chainid', ctx.chainId, '-remote', ctx.remote, ...(ctx.extraFlags ?? []), ctx.keyName ?? 'YOUR_KEY',
  ];
}

export function createCommand(key: SessionKey, grant: Grant, allow: string[], ctx: CommandContext): string {
  const parts = [
    'gnokey', 'maketx', 'session', 'create', '-pubkey', key.pubkey, '-expires-at', expiresArg(grant.expires),
    ...allow.flatMap((a) => ['-allow-paths', a]),
    '-spend-limit', `${grant.spendPerPeriod}ugnot`, '-spend-period', String(grant.period), ...tail(ctx),
  ];
  return parts.map(q).join(' ');
}

export function revokeCommand(pubkey: string, ctx: CommandContext): string {
  return ['gnokey', 'maketx', 'session', 'revoke', '-pubkey', pubkey, ...tail(ctx)].map(q).join(' ');
}

/** No atomic replace from a single gnokey command: create the new session first, then revoke the old one. */
export function replaceCommand(newKey: SessionKey, grant: Grant, allow: string[], oldPubkey: string, ctx: CommandContext): string {
  return `${createCommand(newKey, grant, allow, ctx)} && ${revokeCommand(oldPubkey, ctx)}`;
}
```

```ts
import { ugnot, type ChainApi } from '@/chain/api';
import { decodeAddress } from '@/utils/bech32';

export interface SessionStatus {
  expiresAt: number;
  spendLimit: number;
  spendUsed: number;
  spendReset: number;
  spendPeriod: number;
  allowPaths: string[];
}

export async function querySession(api: ChainApi, master: string, session: string): Promise<SessionStatus | null> {
  let res;
  try {
    res = await api.querySessionAccount(decodeAddress(master), decodeAddress(session));
  } catch (e) {
    if (/session not found|not found/i.test(String((e as Error)?.message ?? e))) return null;
    throw e;
  }
  const a = res.accountInfo;
  if (!a) return null;
  return {
    expiresAt: Number(a.expiresAt), spendLimit: ugnot(a.spendLimit), spendUsed: ugnot(a.spendUsed),
    spendReset: Number(a.spendReset), spendPeriod: Number(a.spendPeriod), allowPaths: [...a.allowPaths],
  };
}

const windowOver = (s: SessionStatus, now: number) => s.spendPeriod > 0 && now >= s.spendReset + s.spendPeriod;

export const remaining = (s: SessionStatus, now: number) =>
  windowOver(s, now) ? s.spendLimit : Math.max(0, s.spendLimit - s.spendUsed);

export const resetsIn = (s: SessionStatus, now: number) =>
  s.spendPeriod > 0 && !windowOver(s, now) ? s.spendReset + s.spendPeriod - now : 0;

export const expiresSoon = (s: SessionStatus, now: number, days = 3) =>
  s.expiresAt > 0 && s.expiresAt - now <= days * 86400;

export async function pollSession(
  api: ChainApi, master: string, session: string, want: 'present' | 'absent',
  opts: { intervalMs: number; signal: { aborted: boolean }; sleep?: (ms: number) => Promise<void> },
): Promise<SessionStatus | null> {
  const sleep = opts.sleep ?? ((ms: number) => new Promise<void>((r) => setTimeout(r, ms)));
  for (;;) {
    if (opts.signal.aborted) throw new Error('cancelled');
    const st = await querySession(api, master, session).catch(() => undefined); // transient errors: try again
    if (st !== undefined && (want === 'present' ? st !== null : st === null)) return st;
    await sleep(opts.intervalMs);
    if (opts.signal.aborted) throw new Error('cancelled');
  }
}
```

```ts
import { createJSONStorage, persist, type StateStorage } from 'zustand/middleware';
import { createStore } from 'zustand/vanilla';

import type { ChainApi } from '@/chain/api';
import { SESSION_ALLOW_PATHS } from '@/chain/realms';
import { isAddress } from '@/utils/address';
import { decodeAddress } from '@/utils/bech32';

import { createCommand, replaceCommand, revokeCommand } from './fallback';
import { buildSessionLink, CALLBACK_URL, grantsKey, signLink, type SessionHost, type WalletReply } from './gnoconnect';
import { createSessionKey, unlockKey, type SecretStore } from './keys';
import { pollSession, querySession, type SessionStatus } from './status';
import type { ActiveSession, Grant, SessionKey } from './types';

export type Phase = 'none' | 'waiting-wallet' | 'desktop' | 'waiting-chain' | 'active' | 'error';

export interface Pending {
  op: 'create' | 'replace' | 'revoke';
  state: string;
  key: SessionKey;
  old?: ActiveSession;
  grant?: Grant;
  master?: string;
  chainId: string;
  via: 'wallet' | 'desktop';
  createdAt: number;
}

export interface SessionDeps {
  api: () => ChainApi;
  secrets: SecretStore;
  storage: StateStorage;
  openURL: (url: string) => Promise<void>;
  randomHex: (bytes: number) => string;
  now: () => number;
  network: () => { chainId: string; remote: string };
  pollIntervalMs?: number;
}

export interface SessionState {
  phase: Phase;
  active?: ActiveSession;
  pending?: Pending;
  status?: SessionStatus;
  command?: string;
  error?: string;
  begin(op: 'create' | 'replace', grant: Grant): Promise<void>;
  revoke(): Promise<void>;
  useDesktop(): void;
  submitMaster(master: string): Promise<void>;
  onReply(r: WalletReply): Promise<void>;
  refresh(): Promise<SessionStatus | null>;
  restore(): Promise<void>;
  cancel(): void;
}

// gnoconnect-session.md: a grant and a renewal are both a `connect` with the new key (a renewal adds `old`).
const HOST: Record<Pending['op'], SessionHost> = { create: 'connect', replace: 'connect', revoke: 'disconnect' };

export const createSessionStore = (d: SessionDeps) => {
  let poll = { aborted: false };
  const interval = d.pollIntervalMs ?? 3000;

  return createStore<SessionState>()(
    persist(
      (set, get) => {
        const fail = (e: unknown) => set({ phase: 'error', error: String((e as Error)?.message ?? e) });

        const commandFor = (p: Pending): string => {
          const ctx = d.network();
          if (p.op === 'create') return createCommand(p.key, p.grant!, SESSION_ALLOW_PATHS, ctx);
          if (p.op === 'replace') return replaceCommand(p.key, p.grant!, SESSION_ALLOW_PATHS, p.old!.pubkey, ctx);
          return revokeCommand(p.key.pubkey, ctx);
        };

        const waitForChain = async (p: Pending, master: string) => {
          poll.aborted = true;
          poll = { aborted: false };
          const signal = poll;
          set({ phase: 'waiting-chain', pending: { ...p, master } });
          try {
            if (p.op === 'revoke') {
              await pollSession(d.api(), master, p.key.address, 'absent', { intervalMs: interval, signal });
              set({ phase: 'none', active: undefined, pending: undefined, status: undefined, command: undefined });
              return;
            }
            const status = await pollSession(d.api(), master, p.key.address, 'present', { intervalMs: interval, signal });
            await unlockKey(d.api(), d.secrets, p.key, master);
            set({
              phase: 'active', active: { ...p.key, master, chainId: p.chainId }, status: status ?? undefined,
              pending: undefined, command: undefined, error: undefined,
            });
          } catch (e) {
            if (!signal.aborted) fail(e);
          }
        };

        /** Show the gnokey command; when the master is known (renewal, revocation, identity-only answer), watch the chain at once. */
        const desktop = (master?: string) => {
          const p = get().pending;
          if (!p) return;
          const next = { ...p, via: 'desktop' as const };
          set({ pending: next, phase: 'desktop', command: commandFor(next) });
          const known = master ?? (p.op === 'create' ? undefined : get().active?.master);
          if (known) void waitForChain(next, known);
        };

        const send = async (p: Pending, link: string) => {
          set({ pending: p, phase: 'waiting-wallet', command: commandFor(p), error: undefined });
          try {
            await d.openURL(link);
          } catch {
            get().useDesktop();
          }
        };

        const linkFor = async (p: Pending): Promise<string> => {
          const net = d.network();
          const api = d.api();
          const link = buildSessionLink({
            host: HOST[p.op], pubkey: p.key.pubkey, old: p.op === 'replace' ? p.old!.pubkey : undefined,
            grant: p.grant, allow: p.op === 'revoke' ? undefined : SESSION_ALLOW_PATHS,
            chainid: net.chainId, rpc: net.remote, signer: p.old?.master ?? (p.op === 'revoke' ? get().active?.master : undefined),
            callback: CALLBACK_URL, state: p.state, iat: Math.floor(d.now() / 1000),
          });
          const signWith = (addr: string) => async (data: Uint8Array) =>
            (await api.signBytes(decodeAddress(addr), data)).signature;
          return signLink(link, signWith(p.key.address), p.op === 'replace' ? signWith(p.old!.address) : undefined);
        };

        return {
          phase: 'none',

          async begin(op, grant) {
            try {
              const old = get().active;
              if (op === 'replace' && !old) throw new Error('no session to replace');
              const key = await createSessionKey(d.api(), d.secrets, d.randomHex, d.now);
              await unlockKey(d.api(), d.secrets, key); // so it can sign the proof
              const p: Pending = {
                op, state: d.randomHex(16), key, old: op === 'replace' ? old : undefined, grant,
                chainId: d.network().chainId, via: 'wallet', createdAt: d.now(),
              };
              await send(p, await linkFor(p));
            } catch (e) {
              fail(e);
            }
          },

          async revoke() {
            try {
              const active = get().active;
              if (!active) throw new Error('no session to revoke');
              const p: Pending = {
                op: 'revoke', state: d.randomHex(16), key: active, chainId: active.chainId, via: 'wallet', createdAt: d.now(),
              };
              await send(p, await linkFor(p));
            } catch (e) {
              fail(e);
            }
          },

          useDesktop() {
            desktop();
          },

          async submitMaster(master) {
            const p = get().pending;
            if (!p) throw new Error('nothing is waiting for an address');
            if (!isAddress(master.trim())) throw new Error('that is not a gno address (g1…, 40 characters)');
            await waitForChain(p, master.trim());
          },

          async onReply(r) {
            const p = get().pending;
            if (!p || r.state !== p.state) return; // not ours: forged, stale or duplicated
            if (r.status === 'cancelled') {
              poll.aborted = true;
              set({ pending: undefined, command: undefined, phase: get().active ? 'active' : 'none' });
              return;
            }
            if (r.status === 'error') {
              if (r.code === 'unsupported_host') return desktop(); // a wallet without `disconnect`
              set({ phase: 'error', error: r.code || 'the wallet reported an error' });
              return;
            }
            const master = p.op === 'create' ? r.address : get().active?.master;
            if (!master || !isAddress(master)) return fail(new Error('the wallet did not say which account granted the session'));
            // An identity-only `connect` answer: the wallet does not grant sessions yet, but it told us the master.
            if (p.op !== 'revoke' && !grantsKey(r, p.key.address)) return desktop(master);
            await waitForChain(p, master);
          },

          async refresh() {
            const a = get().active;
            if (!a) return null;
            const st = await querySession(d.api(), a.master, a.address);
            if (st) set({ status: st });
            return st;
          },

          async restore() {
            const p = get().pending;
            if (p) {
              const master = p.master ?? (p.op === 'create' ? undefined : get().active?.master);
              if (master) void waitForChain(p, master);
              else set({ phase: p.via === 'wallet' ? 'waiting-wallet' : 'desktop', command: commandFor(p) });
            }
            const a = get().active;
            if (!a) return;
            try {
              const st = await querySession(d.api(), a.master, a.address);
              if (!st) {
                set({ active: undefined, status: undefined, phase: get().pending ? get().phase : 'none' });
                return;
              }
              await unlockKey(d.api(), d.secrets, a, a.master);
              set({ status: st, phase: get().pending ? get().phase : 'active' });
            } catch (e) {
              fail(e);
            }
          },

          cancel() {
            poll.aborted = true;
            set({ pending: undefined, command: undefined, error: undefined, phase: get().active ? 'active' : 'none' });
          },
        };
      },
      {
        name: 'br.session',
        storage: createJSONStorage(() => d.storage),
        partialize: (s) => ({ active: s.active, pending: s.pending }),
        // the phase is derived from what was persisted, never stored itself
        merge: (persisted, current) => {
          const p = (persisted ?? {}) as Partial<SessionState>;
          const phase: Phase = p.pending
            ? p.pending.via === 'wallet' ? 'waiting-wallet' : 'desktop'
            : p.active ? 'active' : 'none';
          return { ...current, ...p, phase };
        },
      },
    ),
  );
};
```

```ts
import type { SecretStore } from '@/session/keys';

export class OffchainError extends Error {
  constructor(public status: number, message: string) {
    super(message);
    this.name = 'OffchainError';
  }
}

export interface Offchain {
  get<T>(path: string): Promise<T>;
  post<T>(path: string, body?: unknown): Promise<T>;
}

export function createOffchain(d: {
  baseUrl: () => string;
  bid: () => Promise<string>;
  fetch?: typeof fetch;
  timeoutMs?: number;
}): Offchain {
  const f = d.fetch ?? fetch;
  async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
    const ctrl = new AbortController();
    const timer = setTimeout(() => ctrl.abort(), d.timeoutMs ?? 10000);
    const headers: Record<string, string> = { 'X-Bid': await d.bid() };
    if (body !== undefined) headers['Content-Type'] = 'application/json';
    try {
      const res = await f(d.baseUrl().replace(/\/+$/, '') + path, {
        method, headers, body: body === undefined ? undefined : JSON.stringify(body), signal: ctrl.signal,
      });
      const data = await res.json().catch(() => ({}));
      if (!res.ok) throw new OffchainError(res.status, (data as { error?: string })?.error || `HTTP ${res.status}`);
      return data as T;
    } catch (e) {
      if (e instanceof OffchainError) throw e;
      throw new OffchainError(0, `server unreachable (${(e as Error)?.message ?? e})`);
    } finally {
      clearTimeout(timer);
    }
  }
  return {
    get: (path) => request('GET', path),
    post: (path, body) => request('POST', path, body),
  };
}

const BID_KEY = 'br.bid';

/** The site's per-browser id (X-Bid): 16 hex, kept in the secure store. */
export async function browserId(store: SecretStore, randomHex: (n: number) => string): Promise<string> {
  const have = await store.get(BID_KEY);
  if (have && /^[0-9a-f]{16}$/.test(have)) return have;
  const id = randomHex(8);
  await store.set(BID_KEY, id);
  return id;
}
```

```ts
  const r = await oc.post<unknown>(`/presence?id=${encodeURIComponent(pid)}`);
```

```tsx
import { createContext, useContext, useEffect, useMemo, useRef, type PropsWithChildren } from 'react';
import { AppState } from 'react-native';
import { useStore, type StoreApi } from 'zustand';

import type { ChainApi } from '@/chain/api';
import { GameClient } from '@/chain/game-client';
import { browserId, createOffchain, type Offchain } from '@/offchain/http';
import { presenceStore, sendPresence } from '@/offchain/presence';

interface Services {
  api: ChainApi;
  game: GameClient;
  offchain: Offchain;
  session: StoreApi<SessionState>;
}

const Ctx = createContext<Services | null>(null);

export function AppServices({ children }: PropsWithChildren) {
  const { gnonative } = useGnoNativeContext();
  const api: ChainApi = gnonative; // GnoNativeApi satisfies ChainApi (guarded by _Check in src/chain/api.ts)
  const chainId = useSettings((s) => s.chainId);
  const remote = useSettings((s) => s.remote);

  const services = useMemo<Services>(() => {
    const offchain = createOffchain({
      baseUrl: () => settingsStore.getState().offchainUrl,
      bid: () => browserId(secureStore, randomHex),
    });
    const session = createSessionStore({
      api: () => api,
      secrets: secureStore,
      storage: AsyncStorage,
      openURL: (url) => Linking.openURL(url).then(() => undefined),
      randomHex,
      now: () => Date.now(),
      network: () => {
        const s = settingsStore.getState();
        return { chainId: s.chainId, remote: s.remote };
      },
    });
    return { api, game: new GameClient(api, () => settingsStore.getState().chainId), offchain, session };
  }, [api]);

  // keep gnonative on the configured network
  useEffect(() => {
    void api.setRemote(remote);
    void api.setChainID(chainId);
  }, [api, chainId, remote]);

  // resume a pending session request / re-unlock the active key on launch
  useEffect(() => {
    const s = services.session;
    const go = () => void s.getState().restore();
    if (s.persist.hasHydrated()) go();
    else return s.persist.onFinishHydration(go);
  }, [services]);

  // presence heartbeat: every 20 s while in the foreground
  const pid = useRef(randomHex(8)).current;
  useEffect(() => {
    let timer: ReturnType<typeof setInterval> | undefined;
    const beat = async () => {
      try {
        const r = await sendPresence(services.offchain, pid);
        presenceStore.getState().update({ country: r.you, count: r.count, reachable: true });
      } catch {
        presenceStore.getState().update({ reachable: false }); // play stays open
      }
    };
    const start = () => {
      void beat();
      timer = setInterval(beat, 20000);
    };
    const stop = () => timer && clearInterval(timer);
    start();
    const sub = AppState.addEventListener('change', (st) => (st === 'active' ? start() : stop()));
    return () => {
      stop();
      sub.remove();
    };
  }, [services, pid]);

  return <Ctx.Provider value={services}>{children}</Ctx.Provider>;
}

export function useServices(): Services {
  const s = useContext(Ctx);
  if (!s) throw new Error('useServices outside AppServices');
  return s;
}

export function useSession<T>(sel: (s: SessionState) => T): T {
  return useStore(useServices().session, sel);
```

```ts
import type { Pool } from '@/chain/parse';

export const isLive = (p: Pool, now: number) => !p.cancelled && !p.over && !(p.bids > 0 && p.deadline > 0 && p.deadline <= now);

export function sortPools(pools: Pool[], now: number): { live: Pool[]; closed: Pool[] } {
  const live = pools.filter((p) => isLive(p, now)).sort((a, b) => b.pot - a.pot || b.version - a.version);
  const closed = pools
    .filter((p) => !isLive(p, now))
    .sort((a, b) => Number(a.cancelled) - Number(b.cancelled) || b.deadline - a.deadline || b.createdAt - a.createdAt);
  return { live, closed };
}
```

```ts
import { ChainError } from '@/chain/errors';
import { resetsIn, type SessionStatus } from '@/session/status';
import { humanDuration } from '@/utils/gnot';

export function txMessage(e: unknown, now: number, status?: SessionStatus): string {
  if (!(e instanceof ChainError)) return String((e as Error)?.message ?? e);
  switch (e.kind) {
    case 'budget': {
      const left = status ? resetsIn(status, now) : 0;
      return left > 0
        ? `Session budget used up — it refills in ${humanDuration(left)}.`
        : 'Session budget used up — raise it from the Session tab.';
    }
    case 'expired':
      return 'Your session has expired — renew it from the Session tab.';
    case 'unknown-session':
      return 'Your session was revoked or is unknown to the chain — make a new one from the Session tab.';
    case 'not-allowed':
      return 'Your session does not cover this realm — renew it from the Session tab.';
    case 'funds':
      return 'Your account is out of GNOT — top it up from the Session tab.';
    case 'network':
      return 'The node did not answer — try again.';
    default:
      return e.message;
  }
}
```

```tsx
import { colors, radius, space } from '@/theme';

export interface BoopChoice { flag: string; boost: number; shot: number }

export function BoopPanel({
  pool, realm, me, hasRef, defaultFlag, suggestions, busy, onBoop,
}: {
  pool: Pool; realm?: RealmInfo; me: string; hasRef: boolean; defaultFlag: string; suggestions: string[];
  busy: boolean; onBoop: (c: BoopChoice) => void;
}) {
  const [flag, setFlag] = useState(defaultFlag);
  const [boostIdx, setBoostIdx] = useState(0);
  const [shotBps, setShotBps] = useState(0);
  const c = caps(pool.version);
  const bid = pool.nextPrice * BOOSTS[boostIdx];

  const inputs: ShotInputs = {
    version: pool.version, pot: pool.pot, bids: pool.bids, liveBps: pool.liveBps,
    roster: pool.roster.map((m) => ({ addr: m.addr, paid: m.paid })), me, hasRef,
    revealTip: realm?.split.revealTip ?? 20000, minShot: realm?.split.minShot ?? 100000,
  };

        keeperFresh: realm.split.keeperFresh ?? 300, liveFloor: realm.split.liveFloor ?? 2500, now: realm.now,
      })
    : 'shots are not sold on this bubble';
  const shot = useMemo(() => (shotBps && !pause ? shotFor(inputs, shotBps, bid) : 0), [shotBps, pause, bid, pool]);
  const odds = shot ? oddsBps(inputs, bid, shot) : 0;
  const gas = gasFor('Bid', pool);
  const clock = clockFor(pool.window, pool.nextPrice, bid);

  return (
    <View style={styles.box}>
      {c.flags ? (
        <View style={styles.row}>
          <Text style={styles.label}>play under</Text>
          <TextInput
            style={styles.flagInput} value={flag} maxLength={2} autoCapitalize="characters"
            onChangeText={(t) => setFlag(t.toUpperCase())} placeholder="FR" placeholderTextColor={colors.muted}
          />
          <Text style={styles.flagEmoji}>{flagEmoji(flag)}</Text>
          {suggestions.filter(isFlag).slice(0, 6).map((cc) => (
            <Pressable key={cc} onPress={() => setFlag(cc)}><Text style={styles.chip}>{flagEmoji(cc)}</Text></Pressable>
          ))}
        </View>
      ) : null}
      <Text style={styles.label}>your clock</Text>
      <View style={styles.row}>
        {BOOST_LABELS.map((l, i) => (
          <Pressable key={l} onPress={() => setBoostIdx(i)}>
            <Text style={[styles.chip, i === boostIdx && styles.chipOn]}>{l}</Text>
          </Pressable>
        ))}
      </View>
      {c.shots ? (
        <>
          <Text style={styles.label}>shoot it</Text>
          {pause ? <Text style={styles.muted}>{pause}</Text> : (
            <View style={styles.row}>
              {[0, 25, 50, 100].map((b) => (

                  <Text style={[styles.chip, b === shotBps && styles.chipOn]}>{b === 0 ? 'no shot' : `${(b / 100).toFixed(2)}%`}</Text>

              ))}
            </View>
          )}
          {shot ? <Text style={styles.muted}>{(odds / 100).toFixed(2)}% to pop it · {gnot(shot)} · revealed ~20 s after your boop</Text> : null}
        </>
      ) : null}
      <Text style={styles.muted}>
        clock {humanDuration(clock)} · fee ~{gnot(gas.fee)} · total {gnot(bid + shot + gas.fee)} (+ storage)
      </Text>
      <Button
```

```ts
import type { PoolForm } from '@/chain/game-client';
import { parseDuration, toUgnot } from '@/utils/gnot';

// bubblerumble5's CreatePool bounds
const MIN_WINDOW = 10, MAX_WINDOW = 30 * 86400, MIN_LIFE = 3600, MAX_LIFE = 30 * 86400;
const MIN_BASE = 1000, MAX_BASE = 1_000_000_000_000;

export function validatePoolForm(i: { name: string; window: string; base: string; life: string; seed: string }): { form?: PoolForm; error?: string } {
  try {
    const name = i.name.trim();
    if (name.length < 1 || name.length > 40) return { error: 'name must be 1-40 characters' };
    if (/[\u0000-\u001f\u007f]/.test(name)) return { error: 'name has control characters' };
    const window = parseDuration(i.window);
    if (window < MIN_WINDOW || window > MAX_WINDOW) return { error: 'window must be between 10s and 30d' };
    const basePrice = toUgnot(i.base);
    if (basePrice < MIN_BASE || basePrice > MAX_BASE) return { error: 'base price must be between 0.001 and 1,000,000 GNOT' };
    const life = i.life.trim() ? parseDuration(i.life) : 0;
    if (life !== 0 && (life < MIN_LIFE || life > MAX_LIFE)) return { error: 'life must be between 1h and 30d' };
    if (life !== 0 && life < window) return { error: 'life must be at least the window' };
    return { form: { name, window, basePrice, life, seed: toUgnot(i.seed) } };
  } catch (e) {
    return { error: (e as Error).message };
  }
}
```

```ts
import type { Grant } from '@/session/types';

export function grantFromInput(gnotPerHour: string, days: string): { grant?: Grant; error?: string } {
  try {
    const spend = toUgnot(gnotPerHour);
    if (spend <= 0) return { error: 'the hourly budget must be more than 0 GNOT' };
    const d = Number(days);
    if (!Number.isInteger(d) || d < 1) return { error: 'days must be a whole number, at least 1' };
    if (d > 1460) return { error: 'at most 1460 days (the chain allows about 4 years)' };
    return { grant: { spendPerPeriod: spend, period: 3600, expires: d * 86400 } };
  } catch (e) {
    return { error: (e as Error).message };
  }
}
```

```js
// Usage: node scripts/fetch-realm.mjs <pkgpath> <outdir>
// Copies a realm's files from gno.land mainnet (vm/qfile) into outdir, with a gnomod.toml gnodev can load.
import { mkdirSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';

const [pkg, out] = process.argv.slice(2);
const q = async (path) => {
  const res = await fetch('https://rpc.gno.land:443', {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify({ jsonrpc: '2.0', id: 1, method: 'abci_query', params: { path: 'vm/qfile', data: Buffer.from(path).toString('base64') } }),
  });
  const j = await res.json();
  return Buffer.from(j.result.response.ResponseBase.Data ?? '', 'base64').toString();
};
mkdirSync(out, { recursive: true });
for (const f of (await q(pkg)).split('\n').filter(Boolean)) {
  if (f === 'gnomod.toml') continue;
  writeFileSync(join(out, f), await q(`${pkg}/${f}`));
}
writeFileSync(join(out, 'gnomod.toml'), `module = "${pkg}"\ngno = "0.9"\n`);
console.log(`fetched ${pkg} → ${out}`);
```

```ts
import { createClient } from '@connectrpc/connect';
import { createConnectTransport } from '@connectrpc/connect-node';
import { GnoNativeService } from '@gnolang/gnonative/build/api/vendor/rpc_pb';

import type { ChainApi } from '../src/chain/api';

/** ChainApi over gnonative's goserver (TCP), mirroring GnoNativeApi's wrappers. */
export function nodeChainApi(baseUrl: string): ChainApi {
  const c = createClient(GnoNativeService, createConnectTransport({ baseUrl, httpVersion: '1.1' }));
  return {
    setRemote: (remote) => c.setRemote({ remote }),
    setChainID: (chainId) => c.setChainID({ chainId }),
    render: async (packagePath, args) => (await c.render({ packagePath, args })).result,
    call: async (packagePath, fnc, args, gasFee, gasWanted, signerAddress, send) =>
      c.call({ gasFee, gasWanted, signerAddress, msgs: [{ packagePath, fnc, args, send }] }),
    queryAccount: (address) => c.queryAccount({ address }),
    querySessionAccount: (masterAddress, sessionAddress) => c.querySessionAccount({ masterAddress, sessionAddress }),
    generateRecoveryPhrase: async () => (await c.generateRecoveryPhrase({})).phrase,
    createAccount: async (nameOrBech32, mnemonic, password) => (await c.createAccount({ nameOrBech32, mnemonic, password })).key,
    activateAccount: (nameOrBech32, master) => c.activateAccount(master ? { nameOrBech32, master } : { nameOrBech32 }),
    setPassword: (password, address) => c.setPassword({ password, address }),
    signBytes: (address, data) => c.signBytes({ address, data }),
  };
}
```

```ts
import { createSessionKey, unlockKey, type SecretStore } from '../src/session/keys';

import type { ActiveSession } from '../src/session/types';
import { decodeAddress } from '../src/utils/bech32';

import { nodeChainApi } from './node-chain-api';

const MASTER = 'g1jg8mtutu9khhfwc4nxmuhcpftf0pajdhfvsqf5'; // test1
const env = (k: string) => {
  const v = process.env[k];
  if (!v) throw new Error(`${k} is not set — run through npm run e2e`);
  return v;
};
const ctx = {
  chainId: 'dev', remote: env('E2E_RPC'), keyName: 'test1',
  extraFlags: ['-home', env('E2E_HOME'), '-insecure-password-stdin'],
};
const desktop = (cmd: string) =>
  cmd.split(' && ').forEach((c) => execSync(`printf '\\n' | ${c.replace(/^gnokey /, `${env('E2E_GNOKEY')} `)}`, { stdio: 'pipe' }));

const mem = new Map<string, string>();
const secrets: SecretStore = { get: async (k) => mem.get(k) ?? null, set: async (k, v) => void mem.set(k, v) };
const hex = (n: number) => Array.from({ length: n }, () => Math.floor(Math.random() * 256).toString(16).padStart(2, '0')).join('');
const grant = { spendPerPeriod: 5_000_000, period: 3600, expires: 30 * 86400 };
const fast = { intervalMs: 500, signal: { aborted: false } };

const api = nodeChainApi(env('E2E_GOSERVER'));
const game = new GameClient(api, () => 'dev');
let session: ActiveSession;

beforeAll(async () => {
  await api.setRemote(env('E2E_RPC'));
  await api.setChainID('dev');
});

test('the session key signs a proof of possession', async () => {
  const key = await createSessionKey(api, secrets, hex, () => Date.now());
  await unlockKey(api, secrets, key);
  const link = buildSessionLink({ host: 'connect', pubkey: key.pubkey, allow: SESSION_ALLOW_PATHS, grant, chainid: 'dev', callback: 'bubblerumble://session-callback', state: 's', iat: 1 });

  expect(signed).toMatch(/&sig=[A-Za-z0-9_-]{86}$/); // 64 bytes

  const key = await createSessionKey(api, secrets, hex, () => Date.now());
  desktop(createCommand(key, grant, SESSION_ALLOW_PATHS, ctx));

test('reading other versions does not need a session', async () => {

});
```
