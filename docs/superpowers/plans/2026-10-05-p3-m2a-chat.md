# P3-M2a — the main chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fourth "Chat" tab that reads and writes bubblerumble.net's main chat (long-polling, reply, edit, take back, reactions, poll votes, pins, typing, unread badge), under a free or reserved name and an avatar, verified against a local fake server.

**Architecture:** `src/offchain/chat/` holds pure modules (types, tolerant parser, `merge` reducer, request-level client, identity in SecureStore) and one zustand store that owns the long-poll loop and the actions; `app-services.tsx` starts and stops the loop with the foreground, like presence. Screens only read the store and call its actions. `scripts/fake-offchain/server.ts` is an in-memory Node server implementing the site's M2a endpoints and rules, used by `e2e/` tests and by the simulator.

**Tech Stack:** Expo SDK 57, expo-router (tabs), TypeScript, zustand 5 (vanilla stores), expo-secure-store, @react-native-async-storage/async-storage, expo-image-picker (new), react-native-safe-area-context, jest-expo (unit), jest + babel-preset-expo in Node (e2e), Node 22 `--experimental-strip-types` for the fake server.

**Spec:** `docs/superpowers/specs/2026-10-05-p3-m2a-chat-design.md` (parent: `docs/superpowers/specs/2026-10-01-bubblerumble-mobile-design.md` §5.4–5.7).

## Global Constraints

- Repository `~/bubblerumble`, branch `main` (local only). Code under `src/`, routes only in `src/app/`, kebab-case files, unit tests colocated `*.test.ts(x)`, e2e tests in `e2e/*.e2e.test.ts`.
- Install Expo-compatible packages with `npx expo install <pkg>` only. Before touching an Expo API, read the SDK 57 docs: `https://docs.expo.dev/versions/v57.0.0/`.
- Run `npx expo lint` (zero errors and warnings) and `npx tsc --noEmit` before a task is done.
- No automated test sends a request to `https://bubblerumble.net` other than the recording GETs of Task 2 (run once by hand). Unit tests mock `fetch`; e2e tests talk to the fake server only.
- The off-chain server never blocks the game: chat errors stay in the chat store and the Chat screen.
- Reactions accepted by the site (its `CHATRX`), in this order: `👍 🔥 ❤️ 😂 🤔 🤝 👎`.
- Edit and take-back window: 900 s (15 min). Take back applies only to the newest line of the chat, when it is yours.
- Long poll: first call `since=0&wait=0&limit=80`, then `since=<cursor>&wait=55&limit=200&gen=<gen>`; request timeout 20 s for the first call, 70 s after. 429/503: wait `Retry-After` (default 6 s) plus a random 0–6 s. Network error: backoff 2 s doubling up to 60 s.
- Typing signal at most every 3 s; `n = 0` clears it, sent once.
- Identity secrets in SecureStore under `br.chat.name`, `br.chat.namekey`, `br.chat.reserved`, `br.chat.av`, `br.chat.avkey` (empty string = none). Last seen line id in AsyncStorage under `br.chat.seen`. The existing `br.bid` (X-Bid) is unchanged.
- Write requests carry `X-Name-Key` when a name is reserved (post, edit, withdraw, react, vote, name release, avatar, boop report); `X-Bid` is always sent by `http.ts`.
- Fake server: `npm run fake-offchain` on port 8787 (`127.0.0.1`); test-only routes live under `/__test/`.
- UI copy in English, like the rest of the app.
- Commits: identity configured globally, no attribution trailer.

## Review Focus

- **The app goes to the background in the middle of a 55 s long poll:** the loop must abort the request and not start another until the app is active again (pinned in Task 5, "stop aborts the in-flight poll").
- **The server URL changes in Settings while the chat is loaded:** lines from the old server must not mix with the new one's (pinned in Task 5, "restart clears the view", and Task 8 wiring).
- **A line arrives as `upd` for an id the app never loaded (older than the window):** it must not be inserted out of place (pinned in Task 3).
- **First install with a busy chat:** the badge must not show the 80 backlog lines as unread (pinned in Task 5).
- **A refused post (reserved name, rate limit, server down):** the typed text stays in the composer and the server's words are shown (pinned in Task 5, "a refused post keeps an error", and Task 8 composer).

```ts
export class OffchainError extends Error {
  constructor(public status: number, message: string, public retryAfter?: number) {
    super(message);
    this.name = 'OffchainError';
  }
}

export interface RequestOptions {
  headers?: Record<string, string>;
  timeoutMs?: number;
  /** aborts the request from outside (the chat loop stopping) */
  signal?: AbortSignal;
  /** a raw body (an avatar's bytes) instead of JSON */
  raw?: { body: Blob | Uint8Array; contentType: string };
}

export interface Offchain {
  get<T>(path: string, o?: RequestOptions): Promise<T>;
  post<T>(path: string, body?: unknown, o?: RequestOptions): Promise<T>;
  patch<T>(path: string, body: unknown, o?: RequestOptions): Promise<T>;
  del<T>(path: string, o?: RequestOptions): Promise<T>;
}

export function createOffchain(d: {
  baseUrl: () => string;
  bid: () => Promise<string>;
  fetch?: typeof fetch;
  timeoutMs?: number;
}): Offchain {
  const f = d.fetch ?? fetch;
  async function request<T>(method: string, path: string, body?: unknown, o: RequestOptions = {}): Promise<T> {
    const ctrl = new AbortController();
    const timer = setTimeout(() => ctrl.abort(), o.timeoutMs ?? d.timeoutMs ?? 10000);
    const outside = () => ctrl.abort();
    if (o.signal?.aborted) ctrl.abort();
    o.signal?.addEventListener('abort', outside);
    try {
      // the timeout covers the browser id too (it comes from the secure store)
      const bid = await new Promise<string>((resolve, reject) => {
        ctrl.signal.addEventListener('abort', () => reject(new Error('timed out')));
        d.bid().then(resolve, reject);
      });
      const headers: Record<string, string> = { 'X-Bid': bid, ...o.headers };
      let payload: BodyInit | undefined;
      if (o.raw) {
        headers['Content-Type'] = o.raw.contentType;
        payload = o.raw.body as BodyInit;
      } else if (body !== undefined) {
        headers['Content-Type'] = 'application/json';
        payload = JSON.stringify(body);
      }
      const res = await f(d.baseUrl().replace(/\/+$/, '') + path, { method, headers, body: payload, signal: ctrl.signal });
      const data = await res.json().catch(() => ({}));
      if (!res.ok) {
        const retry = Number(res.headers?.get?.('Retry-After')) || undefined;
        throw new OffchainError(res.status, (data as { error?: string })?.error || `HTTP ${res.status}`, retry);
      }
      return data as T;
    } catch (e) {
      if (e instanceof OffchainError) throw e;
      throw new OffchainError(0, `server unreachable (${(e as Error)?.message ?? e})`);
    } finally {
      clearTimeout(timer);
      o.signal?.removeEventListener('abort', outside);
    }
  }
  return {
    get: (path, o) => request('GET', path, undefined, o),
    post: (path, body, o) => request('POST', path, body, o),
    patch: (path, body, o) => request('PATCH', path, body, o),
    del: (path, o) => request('DELETE', path, undefined, o),
  };
}
```

```ts
import type { ChatLine, ChatOlderReply, ChatPoll, ChatPollReply, Typing } from './types';

const num = (x: unknown, d = 0) => (typeof x === 'number' && Number.isFinite(x) ? x : d);
const str = (x: unknown) => (typeof x === 'string' ? x : '');
const obj = (x: unknown): Record<string, unknown> =>
  x && typeof x === 'object' && !Array.isArray(x) ? (x as Record<string, unknown>) : {};
const arr = (x: unknown): unknown[] => (Array.isArray(x) ? x : []);
const byId = (a: ChatLine, b: ChatLine) => a.id - b.id;

export function parseRx(x: unknown): Record<string, number> {
  const rx: Record<string, number> = {};
  for (const [k, v] of Object.entries(obj(x))) if (num(v) > 0) rx[k] = num(v);
  return rx;
}

export function parsePoll(x: unknown): ChatPoll | undefined {
  const p = obj(x);
  if (!Array.isArray(p.opts)) return undefined;
  return { q: str(p.q), opts: arr(p.opts).map(str), votes: arr(p.votes).map((v) => num(v)) };
}

/** A server line; null when it has no usable id. Unknown fields are ignored. */
export function parseLine(x: unknown): ChatLine | null {
  const o = obj(x);
  const id = num(o.id);
  if (!(id > 0)) return null;
  const re = obj(o.re);
  const att = obj(o.att);
  const rxwho: Record<string, string[]> = {};
  for (const [k, v] of Object.entries(obj(o.rxwho))) rxwho[k] = arr(v).filter((s): s is string => typeof s === 'string');
  return {
    id, t: num(o.t), name: str(o.name), tag: str(o.tag), cc: str(o.cc), body: str(o.body),
    re: num(re.id) > 0 ? { id: num(re.id), name: str(re.name), body: str(re.body) } : undefined,
    rx: parseRx(o.rx), rxwho,
    edited: o.ed === true, pinned: o.pinned === true, reserved: o.v === true, av: str(o.av), bot: o.bot === true,
    poll: parsePoll(o.poll),
    att: str(att.url) ? { kind: str(att.kind), url: str(att.url), name: str(att.name) } : undefined,
    clip: str(o.clip),
  };
}

const lines = (x: unknown) => arr(x).map(parseLine).filter((l): l is ChatLine => l !== null);
const orNull = (x: unknown) => (typeof x === 'number' && Number.isFinite(x) ? x : null);

export function parsePollReply(x: unknown): ChatPollReply {
  const o = obj(x);
  const you = obj(o.you);
  const typing: Typing[] = arr(o.typing).map(obj)
    .filter((t) => str(t.name) !== '')
    .map((t) => ({ name: str(t.name), n: num(t.n) }));
  return {
    msgs: lines(o.msgs).sort(byId),
    gone: arr(o.gone).map((n) => num(n)).filter((n) => n > 0),
    upd: lines(o.upd),
    next: orNull(o.next),
    gen: orNull(o.gen),
    pins: lines(o.pins),
    typing,
    here: orNull(o.here),
    you: typeof you.tag === 'string' ? { cc: str(you.cc), tag: str(you.tag) } : null,
  };
}

export function parseOlderReply(x: unknown): ChatOlderReply {
  const o = obj(x);
  return { msgs: lines(o.msgs).sort(byId), more: o.more === true };
}
```

```ts
import type { ChatLine, ChatOlderReply, ChatPollReply, ChatYou, Typing } from './types';

/** Lines kept in memory; older ones come back by scrolling up. */
export const MAX_LINES = 500;

export interface ChatView {
  /** ascending id */
  lines: ChatLine[];
  pins: ChatLine[];
  typing: Typing[];
  here: number;
  you: ChatYou | null;
  /** the long-poll cursor */
  since: number;
  gen: number | null;
  /** older history may exist */
  more: boolean;
}

export const EMPTY_VIEW: ChatView = { lines: [], pins: [], typing: [], here: 0, you: null, since: 0, gen: null, more: true };

const byId = (a: ChatLine, b: ChatLine) => a.id - b.id;

function upsertAll(lines: ChatLine[], add: ChatLine[]): ChatLine[] {
  if (!add.length) return lines;
  const m = new Map(lines.map((l) => [l.id, l]));
  for (const l of add) m.set(l.id, l);
  return [...m.values()].sort(byId);
}

/** The server restarted its log: everything held is stale. */
export const genChanged = (v: ChatView, r: ChatPollReply) => v.gen !== null && r.gen !== null && r.gen !== v.gen;

export function applyPoll(v: ChatView, r: ChatPollReply): ChatView {
  const held = new Set(v.lines.map((l) => l.id));
  const gone = new Set(r.gone);
  let lines = upsertAll(v.lines, [...r.msgs, ...r.upd.filter((l) => held.has(l.id))]).filter((l) => !gone.has(l.id));
  const trimmed = lines.length > MAX_LINES;
  if (trimmed) lines = lines.slice(lines.length - MAX_LINES);
  const newest = r.msgs.reduce((m, l) => Math.max(m, l.id), 0);
  return {
    lines,
    pins: r.pins,
    typing: r.typing,
    here: r.here ?? v.here,
    you: r.you ?? v.you,
    since: Math.max(v.since, newest, r.next ?? 0),
    gen: r.gen ?? v.gen,
    more: trimmed ? true : v.more,
  };
}

export function applyOlder(v: ChatView, r: ChatOlderReply): ChatView {
  return { ...v, lines: upsertAll(v.lines, r.msgs), more: r.more && r.msgs.length > 0 };
}

export const upsertLine = <V extends ChatView>(v: V, l: ChatLine): V => ({ ...v, lines: upsertAll(v.lines, [l]) });

export const removeLine = <V extends ChatView>(v: V, id: number): V => ({ ...v, lines: v.lines.filter((l) => l.id !== id) });

export function patchLine<V extends ChatView>(v: V, id: number, p: Partial<ChatLine>): V {
  const i = v.lines.findIndex((l) => l.id === id);
  if (i < 0) return v;
  const lines = v.lines.slice();
  lines[i] = { ...lines[i], ...p };
  return { ...v, lines };
}

/** As on the site: the server's tag for this client, or a line this app posted. */
export const isMine = (l: ChatLine, you: ChatYou | null, mine: readonly number[]) =>
  (!!you?.tag && l.tag === you.tag) || mine.includes(l.id);

export const unreadCount = (v: { lines: ChatLine[]; you: ChatYou | null }, lastSeen: number, mine: readonly number[]) =>
  v.lines.filter((l) => l.id > lastSeen && !isMine(l, v.you, mine)).length;
```

```ts
import type { SecretStore } from '@/session/keys';

/** The chat's local secrets, as on the site. '' means none. */
export interface ChatIdentity {
  name: string;
  /** the reserved name's key (X-Name-Key) */
  nameKey: string;
  reservedName: string;
  av: string;
  avkey: string;
}

export const NO_IDENTITY: ChatIdentity = { name: '', nameKey: '', reservedName: '', av: '', avkey: '' };

const KEYS: Record<keyof ChatIdentity, string> = {
  name: 'br.chat.name', nameKey: 'br.chat.namekey', reservedName: 'br.chat.reserved', av: 'br.chat.av', avkey: 'br.chat.avkey',
};

export interface IdentityStore {
  load(): Promise<ChatIdentity>;
  save(p: Partial<ChatIdentity>): Promise<ChatIdentity>;
}

export function createIdentityStore(s: SecretStore): IdentityStore {
  const fields = Object.keys(KEYS) as (keyof ChatIdentity)[];
  const load = async (): Promise<ChatIdentity> => {
    const values = await Promise.all(fields.map((f) => s.get(KEYS[f])));
    return Object.fromEntries(fields.map((f, i) => [f, values[i] ?? ''])) as unknown as ChatIdentity;
  };
  return {
    load,
    save: async (p) => {
      for (const f of fields) if (p[f] !== undefined) await s.set(KEYS[f], p[f]!);
      return load();
    },
  };
}
```

```ts
  withdraw(): Promise<number | null>;

  reportBoop(addr: string, pool: number, n: number, v: number): Promise<void>;

export function createChatClient(oc: Offchain, identity: () => Promise<ChatIdentity>): ChatClient {
  const keyed = async () => {
    const id = await identity();
    return { id, headers: id.nameKey ? { 'X-Name-Key': id.nameKey } : ({} as Record<string, string>) };
  };
  const lineOf = (r: Obj): ChatLine => {
    const l = parseLine(r?.msg);
    if (!l) throw new OffchainError(0, 'the chat answered without the line');
    return l;
  };
  return {
    poll: async (q, o) => {
      const gen = q.gen !== null ? `&gen=${q.gen}` : '';
      const r = await oc.get<unknown>(`/api/chat?since=${q.since}&wait=${q.wait}&limit=${q.limit}${gen}`, o);
      return parsePollReply(r);
    },
    older: async (before) => parseOlderReply(await oc.get<unknown>(`/api/chat?before=${before}&limit=100`)),
    post: async (name, body, re) => {
      const { id, headers } = await keyed();
      const payload = { name, body, ...(re ? { re } : {}), ...(id.av ? { av: id.av, avkey: id.avkey } : {}) };
      return lineOf(await oc.post<Obj>('/api/chat', payload, { headers }));
    },
    edit: async (lineId, body) => {
      const { headers } = await keyed();
      return lineOf(await oc.patch<Obj>(`/api/chat?id=${lineId}`, { body }, { headers }));
    },
    withdraw: async () => {
      const { headers } = await keyed();
      const r = await oc.post<Obj>('/api/chat/withdraw', undefined, { headers });
      return typeof r?.deleted === 'number' && r.deleted > 0 ? r.deleted : null;
    },
    react: async (lineId, emoji, name) => {
      const { headers } = await keyed();
      const r = await oc.post<Obj>('/api/chat/react', { id: lineId, emoji, name }, { headers });
      return { rx: parseRx(r?.rx), mine: r?.mine === true };
    },
    vote: async (lineId, opt) => {
      const { headers } = await keyed();
      const r = await oc.post<Obj>('/api/chat/vote', { id: lineId, opt }, { headers });
      return { mine: typeof r?.mine === 'number' ? r.mine : -1, poll: parsePoll(r?.poll) };
    },
    typing: async (name, n) => {
      await oc.post('/api/chat/typing', { name, n });
    },
    reserveName: async (name) => {
      const { headers } = await keyed();
      const r = await oc.post<Obj>('/api/name', { name }, { headers });
      if (!str(r?.key)) throw new OffchainError(0, 'the server answered without the name key');
      return { name: str(r.name) || name, key: str(r.key), addr: str(r.addr) };
    },
    releaseName: async () => {
      const { headers } = await keyed();
      await oc.del('/api/name', { headers });
    },
    uploadAvatar: async (body, contentType) => {
      const { headers } = await keyed();
      const r = await oc.post<Obj>('/api/avatar', undefined, { headers, raw: { body, contentType } });
      if (!str(r?.id)) throw new OffchainError(0, 'the server answered without the picture id');
      return { id: str(r.id), key: str(r.key) };
    },
    reportBoop: async (addr, pool, n, v) => {
      const { headers } = await keyed();
      await oc.post('/api/bubble/boop', { addr, pool, n, v }, { headers });
    },
  };
}
```

```ts
      await ready;
      let first = true;
      let backoff = BACKOFF_MIN;
      set({ phase: 'loading' });
      while (!signal.aborted) {
        const v = get();
        try {
          const r = await d.client.poll(
            first ? { since: 0, wait: 0, limit: 80, gen: null } : { since: v.since, wait: 55, limit: 200, gen: v.gen },
            { timeoutMs: first ? 20_000 : 70_000, signal },
          );
          if (signal.aborted) return;
          if (!first && genChanged(v, r)) {
            set({ ...EMPTY_VIEW });
            first = true;
            continue;
          }
          set({ ...applyPoll(first ? EMPTY_VIEW : get(), r), phase: 'live' });
          if (first) await settleSeen();
          first = false;
          backoff = BACKOFF_MIN;
        } catch (e) {
          if (signal.aborted) return;
          if (e instanceof OffchainError && (e.status === 429 || e.status === 503)) {
            await sleep(((e.retryAfter ?? 6) + random() * 6) * 1000, signal);
            continue;
          }
          set({ phase: 'unreachable' });
          await sleep(backoff, signal);
          backoff = Math.min(backoff * 2, BACKOFF_MAX);
        }
      }
    };

    const act = async (f: () => Promise<void>): Promise<boolean> => {
      try {
        await f();
        set({ error: '' });
        return true;
      } catch (e) {
        set({ error: say(e) });
        return false;
      }
    };

    return {
      ...EMPTY_VIEW,
      phase: 'idle',
      lastSeen: 0,
      mine: [],
      myReactions: {},
      myVotes: {},
      identity: NO_IDENTITY,
      error: '',
      start: () => {
        if (run) return;
        run = new AbortController();
        void loop(run.signal);
      },
      stop: () => {
        run?.abort();
        run = null;
        set({ phase: 'idle' });
      },
      restart: () => {
        get().stop();
        set({ ...EMPTY_VIEW, mine: [], myReactions: {}, myVotes: {} });
        get().start();
      },
      loadOlder: async () => {
        const oldest = get().lines[0]?.id;
        if (olderBusy || !get().more || !oldest) return;
        olderBusy = true;
        try {
          const r = await d.client.older(oldest);
          set(applyOlder(get(), r));
        } catch {
          // history is best effort: the next scroll tries again
        } finally {
          olderBusy = false;
        }
      },
      send: async (body, re) => {
        const text = body.trim();
        if (!text) return false;
        const ok = await act(async () => {
          const l = await d.client.post(name(), text, re);
          set((s) => ({ ...upsertLine(s, l), mine: [...s.mine, l.id] }));
        });
        if (ok) typingAt = typingN = 0; // the server drops the sender's typing with the line
        return ok;
      },
      edit: (id, body) =>
        act(async () => {
          const l = await d.client.edit(id, body.trim());
          set((s) => upsertLine(s, l));
        }),
      withdraw: async () => {
        const taken: { id: number | null } = { id: null };
        const ok = await act(async () => {
          taken.id = await d.client.withdraw();
        });
        if (!ok) return false;
        const id = taken.id;
        if (id === null) {
          set({ error: 'Only your newest line in the chat, under fifteen minutes old, can be taken back.' });
          return false;
        }
        set((s) => removeLine(s, id));
        return true;
      },
      react: async (id, emoji) => {
        await act(async () => {
          const r = await d.client.react(id, emoji, name());
          set((s) => {
            const had = (s.myReactions[id] ?? []).filter((e) => e !== emoji);
            return { ...patchLine(s, id, { rx: r.rx }), myReactions: { ...s.myReactions, [id]: r.mine ? [...had, emoji] : had } };
          });
        });
      },
      vote: async (id, opt) => {
        await act(async () => {
          const r = await d.client.vote(id, opt);
          set((s) => ({ ...(r.poll ? patchLine(s, id, { poll: r.poll }) : s), myVotes: { ...s.myVotes, [id]: r.mine } }));
        });
      },
      signalTyping: (n) => {
        const t = now();
        if (n === 0 && typingN === 0) return;
        if (n > 0 && t - typingAt < TYPING_EVERY) return;
        typingAt = n > 0 ? t : 0;
        typingN = n;
        void d.client.typing(name(), n).catch(() => undefined);
      },
      markSeen: () => {
        const newest = get().lines.at(-1)?.id ?? 0;
        if (newest <= get().lastSeen) return;
        seenLoaded = newest;
        set({ lastSeen: newest });
        void d.kv.setItem(SEEN_KEY, String(newest)).catch(() => undefined);
      },
      setName: async (n) => {
        if (get().identity.reservedName) return; // a reserved name is released first
        set({ identity: await d.identity.save({ name: n.trim() }) });
      },
      reserveName: () =>
        act(async () => {
          const r = await d.client.reserveName(get().identity.name.trim());
          set({ identity: await d.identity.save({ name: r.name, reservedName: r.name, nameKey: r.key }) });
        }),
      releaseName: () =>
        act(async () => {
          try {
            await d.client.releaseName();
          } catch (e) {
            if (!(e instanceof OffchainError && e.status === 404)) throw e; // the server no longer has it: nothing to release
          }
          set({ identity: await d.identity.save({ reservedName: '', nameKey: '' }) });
        }),
      setAvatar: (body, contentType) =>
        act(async () => {
          const r = await d.client.uploadAvatar(body, contentType);
          set({ identity: await d.identity.save({ av: r.id, avkey: r.key }) });
        }),
      clearError: () => set({ error: '' }),
    };
  });

  const ready = d.identity.load().then(
    (identity) => store.setState({ identity }),
    () => undefined,
  );
  return Object.assign(store, { ready });
}
```

```ts
interface Line {

const tagOf = (bid: string) => createHash('sha256').update(bid).digest('hex').slice(0, 4);
const fold = (s: string) => s.toLowerCase().normalize('NFKD').replace(/[^\p{L}\p{N}]/gu, '');

function wire(l: Line) {
  const rx: Record<string, number> = {};
  const rxwho: Record<string, string[]> = {};
  for (const [e, bids] of Object.entries(l.rxBy)) if (bids.length) {
    rx[e] = bids.length;
    rxwho[e] = l.rxNames[e] ?? [];
  }
  return {
    id: l.id, t: l.t, name: l.name, tag: l.tag, ...(l.cc ? { cc: l.cc } : {}), body: l.body,
    ...(l.re ? { re: l.re } : {}), ...(Object.keys(rx).length ? { rx, rxwho } : {}),
    ...(l.ed ? { ed: true } : {}), ...(l.pinned ? { pinned: true } : {}), ...(l.v ? { v: true } : {}),
    ...(l.av ? { av: l.av } : {}), ...(l.bot ? { bot: true } : {}), ...(l.poll ? { poll: l.poll } : {}),

        return res.end(a.bytes);

      // test-only routes

        const l = add({ name: String(body.name ?? 'zed'), body: String(body.body ?? 'hi'), author: OTHER, pinned: !!body.pinned, bot: !!body.bot });

        wake();
        return send(res, 200, { gen });
      }

        return send(res, 200, {});
      }

        const l = lines.find((x) => x.id === Number(body.id));

      }
      return send(res, 404, { error: `no route ${route}` });
    } catch (e) {
      return send(res, 500, { error: String(e) });
    }

    close: () =>
      new Promise<void>((resolve) => {
        wake();
        server.closeAllConnections();
        server.close(() => resolve());
      }),
  };
}
```

```ts
import type { ChatLine, ChatPoll, Typing } from '@/offchain/chat/types';

/** The site's window to edit or take back a line, seconds. */
export const EDIT_WINDOW = 900;

export const canEdit = (l: ChatLine, mine: boolean, nowSec: number) => mine && !l.poll && nowSec - l.t < EDIT_WINDOW;

export const canWithdraw = (l: ChatLine, newestId: number, mine: boolean, nowSec: number) =>
  mine && l.id === newestId && nowSec - l.t < EDIT_WINDOW;

export function ago(t: number, nowSec: number): string {
  const s = Math.max(0, nowSec - t);
  if (s < 60) return 'now';
  if (s < 3600) return `${Math.floor(s / 60)}m`;
  if (s < 86400) return `${Math.floor(s / 3600)}h`;
  return `${Math.floor(s / 86400)}d`;
}

const URL_RE = /https?:\/\/[^\s<>"']*[^\s<>"'.,;:!?)\]]/g;

export function splitLinks(body: string): { text: string; url?: string }[] {
  const out: { text: string; url?: string }[] = [];
  let at = 0;
  for (const m of body.matchAll(URL_RE)) {
    if (m.index! > at) out.push({ text: body.slice(at, m.index) });
    out.push({ text: m[0], url: m[0] });
    at = m.index! + m[0].length;
  }
  if (at < body.length) out.push({ text: body.slice(at) });
  return out;
}

/** What stands for an attachment or a voice message until M2c shows them. */
export function placeholder(l: ChatLine): string | null {
  if (l.clip) return '🎤 voice message';
  if (!l.att) return null;
  if (l.att.kind === 'image') return '📎 picture';
  if (l.att.kind === 'video') return '📎 video';
  return `📎 file${l.att.name ? ` · ${l.att.name}` : ''}`;
}

/** The site's words: three typists at most, dots for the length so far. */
export function typingText(typing: Typing[], myName: string): string {
  const me = myName.trim().toLowerCase();
  return typing
    .filter((t) => t.name.trim().toLowerCase() !== me)
    .slice(0, 3)
    .map((t) => `${t.name} is typing ${t.n < 40 ? '·' : t.n < 200 ? '··' : '···'}${t.n >= 200 ? ' a long one' : ''}`)
    .join(' · ');
}

export function pollBars(p: ChatPoll, mine: number | undefined) {
  const total = p.votes.reduce((a, b) => a + (b || 0), 0);
  return {
    total,
    bars: p.opts.map((label, i) => {
      const count = p.votes[i] || 0;
      return { label, count, pct: total ? Math.round((100 * count) / total) : 0, mine: mine === i };
    }),
  };
}
```

```tsx
import { useEffect, useState } from 'react';
import { Pressable, StyleSheet, Text, TextInput, View } from 'react-native';

import type { ChatLine } from '@/offchain/chat/types';
import { colors, radius, space } from '@/theme';

export function Composer({ reply, editing, typing, error, needsName, onNeedName, onCancel, onChange, onSend, onDismissError, bottomInset }: {
  reply: ChatLine | null; editing: ChatLine | null; typing: string; error: string; needsName: boolean;
  onNeedName?: () => void; onCancel: () => void; onChange: (n: number) => void;
  onSend: (text: string) => Promise<boolean>; onDismissError: () => void; bottomInset: number;
}) {
  const [text, setText] = useState('');
  const [busy, setBusy] = useState(false);
  useEffect(() => {
    if (editing) setText(editing.body);
  }, [editing]);
  const strip = editing ? 'editing your line' : reply ? `replying to ${reply.name}: ${reply.body}` : '';
  const send = async () => {
    if (needsName && onNeedName) return onNeedName();
    setBusy(true);
    const ok = await onSend(text); // a refused line keeps its text
    setBusy(false);
    if (ok) {
      setText('');
      onChange(0);
    }
  };
  return (
    <View style={[styles.box, { paddingBottom: space.s + bottomInset }]}>
      {typing ? <Text style={styles.typing} numberOfLines={1}>{typing}</Text> : null}
      {error ? (
        <Pressable onPress={onDismissError}>
          <Text style={styles.error}>{error}</Text>
        </Pressable>
      ) : null}
      {strip ? (
        <View style={styles.strip}>
          <Text style={styles.stripText} numberOfLines={1}>{strip}</Text>
          <Pressable accessibilityRole="button" accessibilityLabel="cancel" onPress={() => {
            onCancel();
            if (editing) setText('');
          }}>
            <Text style={styles.stripText}>✕</Text>
          </Pressable>
        </View>
      ) : null}
      <View style={styles.row}>
        <TextInput
          style={styles.input} value={text} multiline placeholder="say something" placeholderTextColor={colors.muted}
          onChangeText={(t) => {
            setText(t);
            onChange(t.length);
          }}

          style={[styles.send, (busy || !text.trim()) && styles.dim]}>
          <Text style={styles.sendText}>{editing ? 'save' : 'send'}</Text>
        </Pressable>
      </View>
    </View>
  );
}
```

```tsx
            placeholder="anon" placeholderTextColor={colors.muted} autoCapitalize="none" autoCorrect={false} maxLength={32}
          />
          {reserved ? (
            <View style={styles.row}>
              <Text style={styles.ok}>✓ yours</Text>
              <Button kind="secondary" title="Release" disabled={busy} onPress={() => void run(() => store.getState().releaseName())} />
            </View>
          ) : (
            <>
              <Button title="Save name" disabled={busy || !name.trim()} onPress={() => void run(() => store.getState().setName(name))} />
              <Button kind="secondary" title="Reserve this name" disabled={busy || !canReserve || !name.trim()}
                onPress={() => void run(async () => {
                  await store.getState().setName(name);
                  await store.getState().reserveName();
                })} />
              <Text style={styles.muted}>
                {canReserve
                  ? 'A reserved name is yours alone and your lines carry a ✓. The server ties it to the account that booped from this app: boop once first.'
                  : 'Reserving needs a session (Session tab) and one boop from this app.'}
              </Text>
            </>
          )}
          {error ? <Text style={styles.error}>{error}</Text> : null}
          <Button kind="secondary" title="Done" onPress={onClose} />
        </Pressable>
      </Pressable>
    </Modal>
  );
```

```ts
/** When the site reports a boop, counted from the boop (setTimeouts at 4, 9, 16, 30 and 60 s). */
export const REPORT_AT_MS: readonly number[] = [4000, 9000, 16000, 30000, 60000];

/**
 * The site's POST /api/bubble/boop after a boop: the server ties the address to this client by it, which is how a
 * name gets reserved ("one boop does it"). Best effort, never in the way of play.
 */
export async function reportBoop(d: {
  report: (addr: string, pool: number, n: number, v: number) => Promise<void>;
  readPool: () => Promise<{ history: { n: number; bidder: string; at: number }[] }>;
  addr: string;
  version: number;
  poolId: number;
  now: () => number;
  sleep: (ms: number) => Promise<void>;
}): Promise<boolean> {
  const start = d.now();
  for (const at of REPORT_AT_MS) {
    await d.sleep(Math.max(0, start + at - d.now()));
    try {
      const mine = (await d.readPool()).history.filter((h) => h.bidder === d.addr).sort((a, b) => b.n - a.n)[0];
      if (!mine || d.now() / 1000 - mine.at > 600) continue;
      await d.report(d.addr, d.poolId, mine.n, d.version);
      return true;
    } catch {
      // the next step tries again
    }
  }
  return false;
}
```
