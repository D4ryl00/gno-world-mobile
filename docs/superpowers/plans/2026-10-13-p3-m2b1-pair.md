# P3-M2b-1 `/pair` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app pairs with gno.world in a browser, both ways, so both keep the same rooms book and the same reserved name, exactly as two paired browsers do.

**Architecture:** A new `src/offchain/sync/` package copies the site's `/pair` (code → PBKDF2 → AES-GCM blob → shared sealed record `{rooms, left, name, at}` under `sha256(sync key)`). Crypto sits behind a `CryptoBackend` interface: the app's backend is expo-crypto (AES-GCM, SHA-256) plus a new local Expo module `modules/pbkdf2` (CommonCrypto / javax.crypto); tests use `node:crypto`. A zustand store runs the sync loop in the foreground; the rooms book is stored per off-chain server, sealed in AsyncStorage by a local key in SecureStore; the name goes through the chat's existing `IdentityStore`. A `/pair` screen opens from the Chat header. The fake server gains `/api/sync/*` and `mine`; an e2e pits the app's store against the site's own sync code replayed in Node.

**Tech Stack:** Expo SDK 57 (`expo` ~57.0.26), React Native 0.86, TypeScript, zustand, expo-crypto 57 (`AESEncryptionKey`, `aesEncryptAsync`, `aesDecryptAsync`, `AESSealedData`, `digest`, `getRandomBytes`), Expo Modules API (Swift, Kotlin), Jest 29 (jest-expo), @testing-library/react-native, Node 22 (`--experimental-strip-types`), WebCrypto.

**Spec:** `docs/superpowers/specs/2026-10-13-p3-m2b1-pair-design.md` (parents: `2026-10-01-bubblerumble-mobile-design.md` §5.4–5.5, `2026-10-05-p3-m2a-chat-design.md`).

## Global Constraints

- Repo `~/bubblerumble`, branch `main`, local. Nothing is pushed without the user's go-ahead.
- The site is the reference (its live JS, read 2026-10-13). Values copied verbatim:
  - code alphabet `ABCDEFGHJKMNPQRSTUVWXYZ23456789`, 6 characters, each `randomByte % 31`; typed codes: upper-cased, everything but `A-Z2-9` removed, exactly 6;
  - code key: PBKDF2-SHA256, password = code (UTF-8), salt = `"bubblerumble rooms " + code`, **200000** iterations, 32 bytes, AES-GCM;
  - sealed bytes: `iv (12 random bytes) | ciphertext | tag (16)`, standard base64 (with padding);
  - sync key: 32 random bytes; id = lowercase hex SHA-256 of the key (64 chars); presence group = first 16 hex of the id;
  - record: `{rooms: [{id, name, key, at, irc?}], left: {id: ms}, name?: {name, key}, at}`; room id `^[A-Za-z0-9_-]{20}$`; room name ≤ 40 chars, default `private room`; caps 200 rooms with a key, 30 without; name key `^[0-9a-f]{32,64}$`; name ≤ 40 chars;
  - routes: `POST /api/sync/pair {code, blob}` (409 = code in use), `GET /api/sync/pair/<code>` → `{blob}` (single use), `GET /api/sync/<id>` (404 = nothing, `ETag` = version), `PUT /api/sync/<id>` (`text/plain`, `If-Match: <version>`, 412 = changed); `GET /api/name?name=<n>` with `X-Name-Key` → `mine: true|false`;
  - timings: code good 10 min; after giving a code, pull every 5 s for 6 min; pull every 2 min and on return to the foreground; push 1.5 s after a local change; on 412 pull then retry, 3 tries in all; 3 tries to find a free code.
- Error texts, verbatim: `a code is six letters and digits`, `that code did not open the key`, `could not make a code`, `server unreachable — try again`, `this build cannot pair — update the app`; production's 404 text: `no such code — it may have been used, or it is older than ten minutes`, `nothing here yet`.
- Storage keys: `br.sync.key.<keyPart(server)>` (SecureStore, 64 hex, `''` = none), `br.rooms.<keyPart(server)>` (AsyncStorage, sealed), `br.rooms.lock` (SecureStore, 64 hex). `keyPart` is the existing helper of `src/offchain/chat/identity.ts`.
- Deliberate departures from the site (spec §10): the app also pushes when its reserved name changes; the confirmation says `This device leaves its current pairing.` when already paired; a record the key cannot open is never overwritten.
- No automated request to production (spec parent §5.7). No new npm dependency (the local module is not one).
- Never create or edit `ios/` or `android/` by hand (Continuous Native Generation); the local module is autolinked from `modules/`.
- Before "done": `npm test`, `npx tsc --noEmit`, `npx expo lint` with **zero errors and zero warnings**.
- Comments: short, saying why, as in the surrounding code.

## Review Focus

1. A code taken (`GET /api/sync/pair/<code>` consumes it) then the confirmation cancelled: the user is told the code is spent and to get another — not a silent nothing (Task 9 test).
2. "Get a code" or "Pair" tapped twice quickly: one request, one code (Task 7 store test; Task 9 disabled buttons).
3. The off-chain server changed in Settings while an offer is in flight: the late answer leaves the new server's state alone (Task 7 test).
4. A build without the native module (Expo Go, an older dev build): pairing says `this build cannot pair — update the app`, nothing crashes (Task 1 test, Task 7 test).
5. The app sent to the background during the 6-minute fast-pull window and brought back: fast pulls resume until the window ends (Task 7 test).

```ts
import { requireOptionalNativeModule } from 'expo';

interface Pbkdf2Native {
  sha256Hex(password: string, salt: string, iterations: number, length: number): Promise<string>;
}

// null in a build without the module (Expo Go, a dev build made before it existed)
const native = requireOptionalNativeModule<Pbkdf2Native>('Pbkdf2');

export const NO_MODULE = 'this build cannot pair — update the app';

/** PBKDF2-HMAC-SHA256 of UTF-8 strings, native and off the JS thread: 200 000 rounds take many seconds in Hermes. */
export async function pbkdf2Sha256(password: string, salt: string, iterations: number, length: number): Promise<Uint8Array> {
  if (!native) throw new Error(NO_MODULE);
  const hex = await native.sha256Hex(password, salt, iterations, length);
  if (hex.length !== length * 2 || !/^[0-9a-f]*$/.test(hex)) throw new Error('the key derivation answered nonsense');
  return Uint8Array.from(hex.match(/../g) ?? [], (h) => parseInt(h, 16));
}
```

`modules/pbkdf2/ios/Pbkdf2Module.swift`:

```swift
import CommonCrypto
import ExpoModulesCore

// PBKDF2-HMAC-SHA256 for the /pair code (gno.world: 200 000 rounds). AsyncFunction runs off the JS thread.
public class Pbkdf2Module: Module {
  public func definition() -> ModuleDefinition {
    Name("Pbkdf2")

    AsyncFunction("sha256Hex") { (password: String, salt: String, iterations: Int, length: Int) throws -> String in
      let pass = Array(password.utf8)
      let saltBytes = Array(salt.utf8)
      guard !pass.isEmpty, iterations > 0, length > 0 else { throw Pbkdf2Failed(-1) }
      var out = [UInt8](repeating: 0, count: length)
      let status = pass.withUnsafeBufferPointer { p in
        p.baseAddress!.withMemoryRebound(to: Int8.self, capacity: pass.count) { pw in
          CCKeyDerivationPBKDF(
            CCPBKDFAlgorithm(kCCPBKDF2), pw, pass.count, saltBytes, saltBytes.count,
            CCPseudoRandomAlgorithm(kCCPRFHmacAlgSHA256), UInt32(iterations), &out, length)
        }
      }
      guard status == kCCSuccess else { throw Pbkdf2Failed(status) }
      return out.map { String(format: "%02x", $0) }.joined()
    }
  }
}

final class Pbkdf2Failed: GenericException<Int32> {
  override var reason: String { "PBKDF2 failed (\(param))" }
}
```

```kotlin
package expo.modules.pbkdf2

import expo.modules.kotlin.modules.Module
import expo.modules.kotlin.modules.ModuleDefinition
import javax.crypto.SecretKeyFactory
import javax.crypto.spec.PBEKeySpec

// PBKDF2-HMAC-SHA256 for the /pair code (gno.world: 200 000 rounds). AsyncFunction runs off the JS thread.
// The codes are ASCII, so how a provider turns the password's chars into bytes cannot differ.
class Pbkdf2Module : Module() {
  override fun definition() = ModuleDefinition {
    Name("Pbkdf2")

    AsyncFunction("sha256Hex") { password: String, salt: String, iterations: Int, length: Int ->
      require(password.isNotEmpty() && iterations > 0 && length > 0) { "PBKDF2 failed (bad arguments)" }
      val spec = PBEKeySpec(password.toCharArray(), salt.toByteArray(Charsets.UTF_8), iterations, length * 8)
      try {
        SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256").generateSecret(spec).encoded
          .joinToString("") { "%02x".format(it) }
      } finally {
        spec.clearPassword()
      }
    }
  }
}
```

```ts
import { toBase64 } from '@/utils/base64url';

/** What the sync needs from cryptography: the app's backend (expo-crypto + modules/pbkdf2), or Node's in tests. */
export interface CryptoBackend {
  random(n: number): Uint8Array;
  sha256(data: Uint8Array): Promise<Uint8Array>;
  pbkdf2(password: string, salt: string, iterations: number, length: number): Promise<Uint8Array>;
  /** AES-256-GCM, 16-byte tag: iv | ciphertext | tag */
  seal(key: Uint8Array, plain: Uint8Array, iv: Uint8Array): Promise<Uint8Array>;
  /** the reverse of seal; throws when the key does not open it */
  open(key: Uint8Array, sealed: Uint8Array): Promise<Uint8Array>;
}

// gno.world's /pair (app-rooms.js, read 2026-10-13)
export const CODE_ALPHABET = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
export const CODE_ROUNDS = 200_000;
export const BAD_CODE = 'a code is six letters and digits';
export const WRONG_CODE = 'that code did not open the key';

export const hex = (b: Uint8Array) => Array.from(b, (x) => x.toString(16).padStart(2, '0')).join('');
export const unhex = (s: string) => Uint8Array.from(s.match(/../g) ?? [], (h) => parseInt(h, 16));
const unb64 = (s: string) => Uint8Array.from(atob(s), (c) => c.charCodeAt(0));

/** Six characters, each a random byte modulo 31, as the site draws them. */
export const newCode = (c: CryptoBackend) => Array.from(c.random(6), (b) => CODE_ALPHABET[b % 31]).join('');

/** A typed code as the site reads it: upper case, only A–Z and 2–9 kept; '' when that is not six characters. */
export function normalizeCode(s: string): string {
  const t = s.toUpperCase().replace(/[^A-Z2-9]/g, '');
  return t.length === 6 ? t : '';
}

export const codeKey = (c: CryptoBackend, code: string) => c.pbkdf2(code, `bubblerumble rooms ${code}`, CODE_ROUNDS, 32);

export const syncId = async (c: CryptoBackend, key: Uint8Array) => hex(await c.sha256(key));

const sealBytes = async (c: CryptoBackend, key: Uint8Array, plain: Uint8Array) => toBase64(await c.seal(key, plain, c.random(12)));

export async function sealSyncKey(c: CryptoBackend, code: string, syncKey: Uint8Array): Promise<string> {
  return sealBytes(c, await codeKey(c, code), syncKey);
}

export async function openSyncKey(c: CryptoBackend, code: string, blob: string): Promise<Uint8Array> {
  const k = await codeKey(c, code); // a failure here (no native module) keeps its own words
  let key: Uint8Array;
  try {
    key = await c.open(k, unb64(blob));
  } catch {
    throw new Error(WRONG_CODE);
  }
  if (key.length !== 32) throw new Error(WRONG_CODE);
  return key;
}

export const sealJson = (c: CryptoBackend, key: Uint8Array, value: unknown) =>
  sealBytes(c, key, new TextEncoder().encode(JSON.stringify(value)));

export async function openJson(c: CryptoBackend, key: Uint8Array, blob: string): Promise<unknown> {
  return JSON.parse(new TextDecoder().decode(await c.open(key, unb64(blob.trim()))));
}
```

```ts
/** A reply read as text, whatever its status: the sync routes answer 404, 409 and 412 as part of their protocol. */
export interface TextReply {
  status: number;
  text: string;
  etag: string;
}

export interface Offchain {
  get<T>(path: string, o?: RequestOptions): Promise<T>;
  post<T>(path: string, body?: unknown, o?: RequestOptions): Promise<T>;
  patch<T>(path: string, body: unknown, o?: RequestOptions): Promise<T>;
  del<T>(path: string, o?: RequestOptions): Promise<T>;
  exchange(method: 'GET' | 'POST' | 'PUT', path: string, o?: RequestOptions & { text?: string; json?: unknown }): Promise<TextReply>;
}

interface Body {
  payload?: BodyInit;
  type?: string;
}

export function createOffchain(d: {
  baseUrl: () => string;
  bid: () => Promise<string>;
  fetch?: typeof fetch;
  timeoutMs?: number;
}): Offchain {
  const f = d.fetch ?? fetch;
  async function call<T>(method: string, path: string, body: Body, o: RequestOptions, read: (res: Response) => Promise<T>): Promise<T> {
    const ctrl = new AbortController();
    const timer = setTimeout(() => ctrl.abort(), o.timeoutMs ?? d.timeoutMs ?? 10000);
    const outside = () => ctrl.abort();
    if (o.signal?.aborted) ctrl.abort();
    o.signal?.addEventListener('abort', outside);
    try {
      // the timeout covers the browser id too (it comes from the secure store)
      const bid = await new Promise<string>((resolve, reject) => {
        ctrl.signal.addEventListener('abort', () => reject(new Error('timed out')));
        d.bid().then(resolve, reject);
      });
      const headers: Record<string, string> = { 'X-Bid': bid, ...o.headers };
      if (body.type) headers['Content-Type'] = body.type;
      const res = await f(d.baseUrl().replace(/\/+$/, '') + path, { method, headers, body: body.payload, signal: ctrl.signal });
      return await read(res);
    } catch (e) {
      if (e instanceof OffchainError) throw e;
      throw new OffchainError(0, `server unreachable (${(e as Error)?.message ?? e})`);
    } finally {
      clearTimeout(timer);
      o.signal?.removeEventListener('abort', outside);
    }
  }
  function jsonBody(body: unknown, o: RequestOptions): Body {
    if (o.raw) {
      const b = o.raw.body;
      // React Native sends a Blob with its own type, whatever the header says: give it the right one
      const payload = (typeof Blob !== 'undefined' && b instanceof Blob && b.type !== o.raw.contentType
        ? new Blob([b], { type: o.raw.contentType })
        : b) as BodyInit;
      return { payload, type: o.raw.contentType };
    }
    return body !== undefined ? { payload: JSON.stringify(body), type: 'application/json' } : {};
  }
  const request = <T>(method: string, path: string, body?: unknown, o: RequestOptions = {}): Promise<T> =>
    call(method, path, jsonBody(body, o), o, async (res) => {
      const data = await res.json().catch(() => ({}));
      if (!res.ok) {
        const retry = Number(res.headers?.get?.('Retry-After')) || undefined;
        throw new OffchainError(res.status, (data as { error?: string })?.error || `HTTP ${res.status}`, retry);
      }
      return data as T;
    });
  return {
    get: (path, o) => request('GET', path, undefined, o),
    post: (path, body, o) => request('POST', path, body, o),
    patch: (path, body, o) => request('PATCH', path, body, o),
    del: (path, o) => request('DELETE', path, undefined, o),
    exchange: (method, path, o = {}) =>
      call(
        method, path,
        o.text !== undefined ? { payload: o.text, type: 'text/plain' } : o.json !== undefined ? { payload: JSON.stringify(o.json), type: 'application/json' } : {},
        o,
        async (res) => ({ status: res.status, text: await res.text().catch(() => ''), etag: res.headers?.get?.('ETag') ?? '' }),
      ),
  };
}
```

```ts
import { keyPart } from '@/offchain/chat/identity';
import type { KV } from '@/offchain/chat/store';
import type { SecretStore } from '@/session/keys';

import { hex, openJson, sealJson, unhex, type CryptoBackend } from './crypto';

/** One room this app knows, as the site's br.rooms entries: key is the maker's key ('' when not the maker). */
export interface RoomEntry {
  id: string;
  name: string;
  key: string;
  at: number;
  irc?: true;
}

/** The rooms book: the rooms known, and when rooms were left (id → ms). */
export interface Book {
  rooms: RoomEntry[];
  left: Record<string, number>;
}

export const ROOM_ID = /^[A-Za-z0-9_-]{20}$/;
export const KEYED_MAX = 200;
export const PLAIN_MAX = 30;
export const BOOK_KEY = 'br.rooms';
export const LOCK_KEY = 'br.rooms.lock';
export const EMPTY_BOOK: Book = { rooms: [], left: {} };

/** The site's roomsSave caps: the first 200 rooms with a key and the first 30 without. */
export function capRooms(rooms: RoomEntry[]): RoomEntry[] {
  let keyed = 0;
  let plain = 0;
  return rooms.filter((r) => (r.key ? ++keyed <= KEYED_MAX : ++plain <= PLAIN_MAX));
}

/** The site's syncMerge: local entries first, then the incoming ones; anything malformed is dropped. */
export function mergeBook(local: Book, incoming: { rooms?: unknown; left?: unknown }): Book {
  const left = { ...local.left };
  if (incoming.left && typeof incoming.left === 'object') {
    for (const [id, t] of Object.entries(incoming.left as Record<string, unknown>)) {
      if (ROOM_ID.test(id)) left[id] = Math.max(left[id] || 0, Number(t) || 0);
    }
  }
  const byId = new Map<string, RoomEntry>();
  for (const raw of [...local.rooms, ...(Array.isArray(incoming.rooms) ? incoming.rooms : [])]) {
    const e = (raw && typeof raw === 'object' ? raw : {}) as Record<string, unknown>;
    if (typeof e.id !== 'string' || !ROOM_ID.test(e.id)) continue;
    const at = Number(e.at) || 0;
    const had = byId.get(e.id);
    if (had) {
      if (at > had.at) {
        had.at = at;
        had.name = String(e.name || had.name).slice(0, 40);
      }
      if (!had.key && e.key) had.key = String(e.key);
    } else {
      byId.set(e.id, {
        id: e.id, name: String(e.name || 'private room').slice(0, 40), key: String(e.key || ''), at,
        ...(e.irc === true ? { irc: true as const } : {}),
      });
    }
  }
  const rooms = [...byId.values()].filter((r) => !(left[r.id] > r.at)).sort((a, b) => b.at - a.at);
  return { rooms: capRooms(rooms), left };
}

export interface BookStore {
  load(): Promise<Book>;
  save(b: Book): Promise<void>;
}

/**
 * The book of the current off-chain server, sealed in AsyncStorage by a local key kept in SecureStore: room keys open
 * private rooms, and the book outgrows what SecureStore promises to hold. Unreadable means empty.
 */
export function createBookStore(d: { kv: KV; secrets: SecretStore; crypto: CryptoBackend; scope: () => string }): BookStore {
  const at = () => `${BOOK_KEY}.${keyPart(d.scope())}`;
  const readLock = async () => {
    const h = await d.secrets.get(LOCK_KEY);
    return h && /^[0-9a-f]{64}$/.test(h) ? unhex(h) : null;
  };
  let making: Promise<Uint8Array> | null = null;
  const lockForSave = () =>
    (making ??= (async () => {
      const have = await readLock();
      if (have) return have;
      const k = d.crypto.random(32);
      await d.secrets.set(LOCK_KEY, hex(k));
      return k;
    })().catch((e) => {
      making = null;
      throw e;
    }));
  return {
    load: async () => {
      try {
        const [raw, lock] = await Promise.all([d.kv.getItem(at()), readLock()]);
        if (!raw || !lock) return EMPTY_BOOK;
        const v = await openJson(d.crypto, lock, raw);
        return mergeBook(EMPTY_BOOK, v && typeof v === 'object' ? v : {});
      } catch {
        return EMPTY_BOOK;
      }
    },
    save: async (b) => {
      const lock = await lockForSave();
      await d.kv.setItem(at(), await sealJson(d.crypto, lock, { rooms: capRooms(b.rooms), left: b.left }));
    },
  };
}
```

```ts
import type { ChatIdentity } from '@/offchain/chat/identity';

export type NameIssue = 'none' | 'same' | 'taken' | 'kept' | 'refused' | 'unknown';

export interface SyncedName {
  name: string;
  key: string;
}

/** What a name that came in amounts to; take: the name this app adopts. */
export interface NameOutcome {
  issue: NameIssue;
  name: string;
  /** this app's reserved name before ('' when none) */
  had: string;
  take?: SyncedName;
}

export const NAME_KEY = /^[0-9a-f]{32,64}$/;

/** The reserved name this app hands to the paired devices (the site's syncNameOut). */
export const nameOut = (id: ChatIdentity): SyncedName | undefined =>
  id.reservedName && NAME_KEY.test(id.nameKey) ? { name: id.reservedName, key: id.nameKey } : undefined;

/**
 * The site's syncNameIn: the server says whether the key holds the name (true, false, or null when it could not say)
 * before this app takes it; a reserved name this app still holds is kept.
 */
export async function nameIn(
  incoming: unknown, local: ChatIdentity, check: (name: string, key: string) => Promise<boolean | null>,
): Promise<NameOutcome> {
  const t = (incoming && typeof incoming === 'object' ? incoming : {}) as { name?: unknown; key?: unknown };
  if (!NAME_KEY.test(String(t.key ?? '')) || !t.name) return { issue: 'none', name: '', had: '' };
  const key = String(t.key);
  const name = String(t.name).slice(0, 40);
  const had = local.nameKey ? local.reservedName : '';
  if (local.nameKey === key) return { issue: 'same', name, had };
  const take = { name, key };
  const yes = await check(name, key);
  if (had) {
    if (yes === null) return { issue: 'unknown', name, had };
    if (yes === false) return { issue: 'refused', name, had };
    if (had.toLowerCase() === name.toLowerCase()) return { issue: 'taken', name, had, take };
    if ((await check(had, local.nameKey)) !== false) return { issue: 'kept', name, had };
    return { issue: 'taken', name, had, take };
  }
  if (yes === false) return { issue: 'refused', name, had };
  return { issue: yes === null ? 'unknown' : 'taken', name, had, take };
}

/** The site's syncPairWords, word for word. */
export function pairWords(issue: NameIssue, name: string, had: string): string {
  const a = name || 'the name';
  const n = 'paired — your chat rooms are the same on both devices';
  const o = had && had.toLowerCase() !== name.toLowerCase() ? had : '';
  switch (issue) {
    case 'taken':
      return `${n}, and the name ${a} is yours here too ✓${o ? ` — it replaces ${o}, whose key the box no longer honoured` : ''}`;
    case 'same':
      return `${n}; this device already had the name ${a} ✓`;
    case 'kept':
      return `${n}. This device keeps its own name ${o}; the other device's name ${a} stays there`;
    case 'refused':
      return `${n}, but the name ${a} did NOT come along: the device the code came from holds an old key for it. /dm jae there to free the name, reserve it again there, then pair once more`;
    case 'unknown':
      return `${n}; the name ${a} could not be checked with the box just now — it is checked again within two minutes`;
    default:
      return `${n}. The other device holds no reserved name, so none came along`;
  }
}
```

```ts
import { OffchainError, type Offchain, type TextReply } from '@/offchain/http';

export interface SyncClient {
  /** 'taken': the code is in use, draw another */
  pairPost(code: string, blob: string): Promise<'ok' | 'taken'>;
  /** the code's blob (a code works once) */
  pairGet(code: string): Promise<string>;
  /** the shared record and its version; nothing yet is version 0 */
  pull(id: string): Promise<{ version: number; blob: string | null }>;
  /** ok: false when another device wrote since `version` (412) */
  push(id: string, version: number, blob: string): Promise<{ ok: true; version: number } | { ok: false }>;
  /** whether the key holds the name; null when the server could not say */
  checkName(name: string, key: string): Promise<boolean | null>;
}

const NO_CACHE = { 'Cache-Control': 'no-store' };

const parsed = (r: TextReply): Record<string, unknown> => {
  try {
    const v: unknown = JSON.parse(r.text);
    return v && typeof v === 'object' ? (v as Record<string, unknown>) : {};
  } catch {
    return {};
  }
};

const fail = (r: TextReply, what: string): never => {
  const e = parsed(r).error;
  throw new OffchainError(r.status, typeof e === 'string' && e ? e : `${what} (${r.status})`);
};

const versionOf = (etag: string): number | null => {
  const n = Number(etag.replace(/^W\//, '').replace(/"/g, ''));
  return etag && Number.isFinite(n) && n > 0 ? n : null;
};

const ok = (r: TextReply) => r.status >= 200 && r.status < 300;

export function createSyncClient(oc: Offchain): SyncClient {
  return {
    pairPost: async (code, blob) => {
      const r = await oc.exchange('POST', '/api/sync/pair', { json: { code, blob } });
      if (r.status === 409) return 'taken';
      return ok(r) ? 'ok' : fail(r, 'could not make a code');
    },
    pairGet: async (code) => {
      const r = await oc.exchange('GET', `/api/sync/pair/${encodeURIComponent(code)}`, { headers: NO_CACHE });
      if (r.status !== 200) fail(r, 'no such code');
      const blob = parsed(r).blob;
      if (typeof blob !== 'string' || !blob) throw new OffchainError(r.status, 'no such code');
      return blob;
    },
    pull: async (id) => {
      const r = await oc.exchange('GET', `/api/sync/${id}`, { headers: NO_CACHE });
      if (r.status === 404) return { version: 0, blob: null };
      if (r.status !== 200) fail(r, 'sync read failed');
      return { version: versionOf(r.etag) ?? 0, blob: r.text.trim() };
    },
    push: async (id, version, blob) => {
      const r = await oc.exchange('PUT', `/api/sync/${id}`, { text: blob, headers: { 'If-Match': String(version) } });
      if (r.status === 412) return { ok: false };
      if (!ok(r)) fail(r, 'sync write failed');
      return { ok: true, version: versionOf(r.etag) ?? version + 1 };
    },
    checkName: async (name, key) => {
      try {
        const r = await oc.exchange('GET', `/api/name?name=${encodeURIComponent(name)}`, { headers: { 'X-Name-Key': key, ...NO_CACHE } });
        if (r.status !== 200) return null;
        const v: unknown = JSON.parse(r.text);
        return !!v && typeof v === 'object' && (v as { mine?: unknown }).mine === true;
      } catch {
        return null;
      }
    },
  };
}
```

```ts
// Test helpers for the sync: a server in memory with the site's rules, and an app around a store.
import { createIdentityStore } from '@/offchain/chat/identity';
import { OffchainError } from '@/offchain/http';

import type { SyncClient } from './client';
import type { CryptoBackend } from './crypto';
import { nodeCrypto } from './node-crypto';
import { createBookStore } from './rooms';
import { createSyncStore } from './store';

/** One PBKDF2 round: both sides of a test use it, so codes still open, fast. */
export const fastCrypto: CryptoBackend = { ...nodeCrypto, pbkdf2: (p, s, _i, l) => nodeCrypto.pbkdf2(p, s, 1, l) };

export function memorySync() {
  const codes = new Map<string, string>();
  const records = new Map<string, { v: number; blob: string }>();
  const names = new Map<string, string>(); // lower-cased name → key
  const calls: string[] = [];
  const client: SyncClient = {
    pairPost: async (code, blob) => {
      calls.push(`pair ${code}`);
      if (codes.has(code)) return 'taken';
      codes.set(code, blob);
      return 'ok';
    },
    pairGet: async (code) => {
      calls.push(`get ${code}`);
      const blob = codes.get(code);
      if (!blob) throw new OffchainError(404, 'no such code — it may have been used, or it is older than ten minutes');
      codes.delete(code);
      return blob;
    },
    pull: async (id) => {
      calls.push('pull');
      const r = records.get(id);
      return r ? { version: r.v, blob: r.blob } : { version: 0, blob: null };
    },
    push: async (id, version, blob) => {
      calls.push('push');
      if ((records.get(id)?.v ?? 0) !== version) return { ok: false };
      records.set(id, { v: version + 1, blob });
      return { ok: true, version: version + 1 };
    },
    checkName: async (name, key) => names.get(name.toLowerCase()) === key,
  };
  return { client, codes, records, names, calls };
}

export function syncApp(server: ReturnType<typeof memorySync>, scope = 'http://fake') {
  const secrets = new Map<string, string>();
  const kv = new Map<string, string>();
  const sec = { get: async (k: string) => secrets.get(k) ?? null, set: async (k: string, v: string) => void secrets.set(k, v) };
  let where = scope;
  const identity = createIdentityStore(sec, () => where);
  const book = createBookStore({
    kv: { getItem: async (k) => kv.get(k) ?? null, setItem: async (k, v) => void kv.set(k, v) },
    secrets: sec, crypto: fastCrypto, scope: () => where,
  });
  let reloads = 0;
  const store = createSyncStore({
    client: server.client, crypto: fastCrypto, secrets: sec, book, identity, identityChanged: () => void reloads++, scope: () => where,
  });
  live.push(store);
  return { store, identity, book, secrets, reloads: () => reloads, setScope: (s: string) => (where = s) };
}

const live: ReturnType<typeof createSyncStore>[] = [];
/** stops every test app's timers (afterEach), so no interval outlives its test */
export const pauseAll = () => {
  for (const s of live.splice(0)) s.getState().pause();
};

export const until = async (f: () => boolean, ms = 5000) => {
  const end = Date.now() + ms;
  while (!f()) {
    if (Date.now() > end) throw new Error('timed out');
    await new Promise((r) => setTimeout(r, 10));
  }
};
```

```ts
import { createStore, type StoreApi } from 'zustand/vanilla';

import { keyPart, type IdentityStore } from '@/offchain/chat/identity';
import { OffchainError } from '@/offchain/http';
import type { SecretStore } from '@/session/keys';

import type { SyncClient } from './client';
import { BAD_CODE, hex, newCode, normalizeCode, openJson, openSyncKey, sealJson, sealSyncKey, syncId, unhex, type CryptoBackend } from './crypto';
import { nameIn, nameOut, pairWords, type NameIssue, type NameOutcome } from './name';
import { mergeBook, type BookStore, type RoomEntry } from './rooms';

export const SYNC_KEY = 'br.sync.key';
// the site's rhythm (app-rooms.js)
export const CODE_LIFE = 600_000;
export const FAST_EVERY = 5_000;
export const FAST_FOR = 360_000;
export const SLOW_EVERY = 120_000;
export const PUSH_AFTER = 1_500;

export interface SyncState {
  paired: boolean;
  /** the first 16 hex of the sync id while paired: presence counts paired devices once */
  group: string;
  /** the code this app gave, while it is good */
  code: { code: string; until: number } | null;
  /** the name's outcome worth saying, in the site's words */
  said: { issue: NameIssue; words: string } | null;
  rooms: RoomEntry[];
  /** ms of the last read or write that went through; 0 none */
  lastSync: number;
  failing: boolean;
  busy: 'offer' | 'accept' | null;
  offerError: string;
  acceptError: string;
  /** foreground: read the stored key and book, pull, run the timers */
  resume(): void;
  /** background: timers off */
  pause(): void;
  /** another off-chain server: everything from scratch */
  restart(): void;
  /** a code for another device; null when it failed (offerError says why) */
  offer(): Promise<string | null>;
  /** the sync key a typed code opens (the code is spent); null when it failed (acceptError says why) */
  open(code: string): Promise<Uint8Array | null>;
  /** adopts another device's sync key; the words to show, or null when it failed */
  use(key: Uint8Array): Promise<string | null>;
  /** this device stops syncing: the key is forgotten, the book and the name stay */
  stop(): Promise<void>;
  /** the book or the name changed here: push soon */
  changed(): void;
  clearError(): void;
}

export interface SyncDeps {
  client: SyncClient;
  crypto: CryptoBackend;
  secrets: SecretStore;
  book: BookStore;
  identity: IdentityStore;
  /** a name came in: the chat reads the identity again */
  identityChanged(): void;
  /** the off-chain server: each has its own pairing */
  scope: () => string;
}

const say = (e: unknown) =>
  e instanceof OffchainError
    ? e.status !== 0 ? e.message : 'server unreachable — try again'
    : e instanceof Error ? e.message : 'server unreachable — try again';

export function createSyncStore(d: SyncDeps): StoreApi<SyncState> {
  let key: Uint8Array | null = null;
  let id = '';
  let version = 0;
  let loaded = false;
  let active = false;
  // bumped by stop() and restart(): an answer to a request made before is about another pairing
  let epoch = 0;
  let fastUntil = 0;
  let slow: ReturnType<typeof setInterval> | undefined;
  let fast: ReturnType<typeof setInterval> | undefined;
  let pushTimer: ReturnType<typeof setTimeout> | undefined;
  let lastName: NameOutcome | null = null;
  // one network exchange at a time: a pull never crosses a push
  let queue: Promise<unknown> = Promise.resolve();
  const serial = <T>(f: () => Promise<T>): Promise<T> => {
    const p = queue.then(f, f);
    queue = p.catch(() => undefined);
    return p;
  };
  const keyName = () => `${SYNC_KEY}.${keyPart(d.scope())}`;

  return createStore<SyncState>()((set, get) => {
    const load = async (e: number) => {
      const [h, book] = await Promise.all([d.secrets.get(keyName()), d.book.load()]);
      if (e !== epoch) return;
      if (h && /^[0-9a-f]{64}$/.test(h)) {
        const k = unhex(h);
        const kid = await syncId(d.crypto, k);
        if (e !== epoch) return;
        key = k;
        id = kid;
        set({ paired: true, group: kid.slice(0, 16) });
      }
      loaded = true;
      set({ rooms: book.rooms });
    };

    /** reads the shared record, merges the book, settles the name; false when it could not */
    const pull = async (e: number): Promise<boolean> => {
      const k = key;
      if (!k) return false;
      try {
        const r = await d.client.pull(id);
        if (e !== epoch) return false;
        if (r.blob) {
          const v = await openJson(d.crypto, k, r.blob);
          const rec = (v && typeof v === 'object' ? v : {}) as { rooms?: unknown; left?: unknown; name?: unknown };
          const book = mergeBook(await d.book.load(), rec);
          await d.book.save(book);
          const n = await nameIn(rec.name, await d.identity.load(), d.client.checkName);
          if (e !== epoch) return false;
          if (n.take) {
            await d.identity.save({ name: n.take.name, reservedName: n.take.name, nameKey: n.take.key });
            d.identityChanged();
          }
          lastName = n;
          set({
            rooms: book.rooms,
            ...(n.issue !== 'none' && n.issue !== 'same' ? { said: { issue: n.issue, words: pairWords(n.issue, n.name, n.had) } } : {}),
          });
        }
        // only a record this key opened moves the version: one it cannot open is never written over
        version = r.version;
        set({ lastSync: Date.now(), failing: false });
        return true;
      } catch {
        if (e === epoch) set({ failing: true });
        return false;
      }
    };

    /** writes this device's book and name; on 412 reads, merges and tries again, 3 tries in all */
    const push = async (e: number) => {
      const k = key;
      if (!k) return;
      try {
        for (let i = 0; i < 3; i++) {
          const book = await d.book.load();
          const blob = await sealJson(d.crypto, k, { rooms: book.rooms, left: book.left, name: nameOut(await d.identity.load()), at: Date.now() });
          const r = await d.client.push(id, version, blob);
          if (e !== epoch) return;
          if (r.ok) {
            version = r.version;
            set({ rooms: book.rooms, lastSync: Date.now(), failing: false });
            return;
          }
          if (!(await pull(e))) return;
        }
      } catch {
        if (e === epoch) set({ failing: true });
      }
    };

    const tick = () => {
      const e = epoch;
      void serial(() => pull(e));
    };
    const startSlow = () => {
      if (active && key && !slow) slow = setInterval(tick, SLOW_EVERY);
    };
    const startFast = () => {
      clearInterval(fast);
      fast = undefined;
      if (!active || Date.now() >= fastUntil) return;
      fast = setInterval(() => {
        if (Date.now() >= fastUntil) {
          clearInterval(fast);
          fast = undefined;
        } else tick();
      }, FAST_EVERY);
    };
    const stopTimers = () => {
      clearInterval(slow);
      clearInterval(fast);
      slow = fast = undefined;
    };

    /** the site's syncUse(key, true): keep the key, read, then write */
    const adopt = async (k: Uint8Array, e: number) => {
      const kid = await syncId(d.crypto, k);
      if (e !== epoch) return;
      await d.secrets.set(keyName(), hex(k));
      if (e !== epoch) return;
      key = k;
      id = kid;
      version = 0;
      set({ paired: true, group: kid.slice(0, 16) });
      await pull(e);
      await push(e);
      startSlow();
    };

    return {
      paired: false, group: '', code: null, said: null, rooms: [], lastSync: 0, failing: false, busy: null, offerError: '', acceptError: '',

      resume: () => {
        if (active) return;
        active = true;
        const e = epoch;
        void serial(async () => {
          if (!loaded) await load(e);
          if (e !== epoch) return;
          if (key) await pull(e);
          startSlow();
          startFast();
        });
      },

      pause: () => {
        active = false;
        stopTimers();
      },

      restart: () => {
        epoch++;
        key = null;
        id = '';
        version = 0;
        loaded = false;
        fastUntil = 0;
        stopTimers();
        clearTimeout(pushTimer);
        set({ paired: false, group: '', code: null, said: null, rooms: [], lastSync: 0, failing: false, busy: null, offerError: '', acceptError: '' });
        if (active) {
          active = false;
          get().resume();
        }
      },

      offer: async () => {
        if (get().busy) return null;
        const e = epoch;
        set({ busy: 'offer', offerError: '' });
        return serial(async () => {
          try {
            if (!loaded) await load(e);
            if (e !== epoch) return null;
            if (!key) await adopt(d.crypto.random(32), e);
            else await push(e);
            const k = key;
            if (e !== epoch || !k) return null;
            for (let i = 0; i < 3; i++) {
              const code = newCode(d.crypto);
              const r = await d.client.pairPost(code, await sealSyncKey(d.crypto, code, k));
              if (e !== epoch) return null;
              if (r === 'ok') {
                fastUntil = Date.now() + FAST_FOR;
                startFast();
                set({ code: { code, until: Date.now() + CODE_LIFE } });
                return code;
              }
            }
            set({ offerError: 'could not make a code' });
            return null;
          } catch (err) {
            if (e === epoch) set({ offerError: say(err) });
            return null;
          } finally {
            if (e === epoch) set({ busy: null });
          }
        });
      },

      open: async (typed) => {
        if (get().busy) return null;
        const code = normalizeCode(typed);
        if (!code) {
          set({ acceptError: BAD_CODE });
          return null;
        }
        const e = epoch;
        set({ busy: 'accept', acceptError: '' });
        try {
          const k = await openSyncKey(d.crypto, code, await d.client.pairGet(code));
          return e === epoch ? k : null;
        } catch (err) {
          if (e === epoch) set({ acceptError: say(err) });
          return null;
        } finally {
          if (e === epoch) set({ busy: null });
        }
      },

      use: async (k) => {
        const e = epoch;
        set({ busy: 'accept', acceptError: '' });
        return serial(async () => {
          try {
            if (!loaded) await load(e);
            lastName = null;
            await adopt(k, e);
            if (e !== epoch) return null;
            const n = lastName ?? { issue: 'none' as const, name: '', had: '' };
            const words = pairWords(n.issue, n.name, n.had);
            set({ said: { issue: n.issue, words }, code: null });
            return words;
          } catch (err) {
            if (e === epoch) set({ acceptError: say(err) });
            return null;
          } finally {
            if (e === epoch) set({ busy: null });
          }
        });
      },

      stop: async () => {
        epoch++;
        const where = keyName();
        key = null;
        id = '';
        version = 0;
        fastUntil = 0;
        stopTimers();
        clearTimeout(pushTimer);
        set({ paired: false, group: '', code: null, said: null, failing: false, busy: null, offerError: '', acceptError: '' });
        // after whatever exchange is under way, so its key write cannot land last
        await serial(() => d.secrets.set(where, ''));
      },

      changed: () => {
        if (!key) return;
        clearTimeout(pushTimer);
        const e = epoch;
        pushTimer = setTimeout(() => void serial(() => push(e)), PUSH_AFTER);
      },

      clearError: () => set({ offerError: '', acceptError: '' }),
    };
  });
}
```

```ts
import { webcrypto } from 'node:crypto';

const crypto = webcrypto as unknown as Crypto;
const SYNCCODE = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
const ROOMRE = /^[A-Za-z0-9_-]{20}$/;

  reserve(name: string, key: string) {

  chatReservedName() {

  roomRemember(t: { id: string; name?: string; key?: string; irc?: boolean }) {

      this.localStorage.setItem('br.syncleft', JSON.stringify(this.SYNC.left));
    }
    this.syncSoon();
  }
  roomForget(t: string) {
    this.roomsSave(this.roomsKnown().filter((x) => x.id !== t));
    this.SYNC.left[t] = Date.now();
    this.localStorage.setItem('br.syncleft', JSON.stringify(this.SYNC.left));
    this.syncSoon();

  async syncUse(t: Uint8Array, e: boolean) {
    this.SYNC.key = await crypto.subtle.importKey('raw', t, 'AES-GCM', false, ['encrypt', 'decrypt']);
    this.SYNC.id = hexOf(new Uint8Array(await crypto.subtle.digest('SHA-256', t)));
    this.localStorage.setItem('br.synckey', hexOf(t));

    await this.syncPull();

      try {

      } catch {

    this.SYNC.v = 0;

    const o = new Uint8Array(12 + n.length);
    o.set(a);
    o.set(n, 12);
    return o;
  }
  async syncOpen(t: Uint8Array, e = this.SYNC.key!) {
    const a = new Uint8Array(t);
    const n = await crypto.subtle.decrypt({ name: 'AES-GCM', iv: a.slice(0, 12) }, e, a.slice(12));
    return JSON.parse(new TextDecoder().decode(n));
  }
  syncNameOut() {
    const t = this.localStorage.getItem('br.namekey');
    const e = this.localStorage.getItem('br.namekeyname');
    return /^[0-9a-f]{32,64}$/.test(t || '') && e ? { name: e, key: t } : undefined;
  }
  async syncNameIn(t: { name?: string; key?: string } | undefined): Promise<string> {

      this.SYNC.nameLast = { o, name: name || '', have: have || '' };
      return o;

    if (!t || !/^[0-9a-f]{32,64}$/.test(String(t.key || '')) || !t.name) return e('none');
    const a = this.chatReservedName();
    const n = String(t.key);
    const o = String(t.name).slice(0, 40);
    const r = this.localStorage.getItem('br.namekey') || '';
    if (r === n) return e('same', o);
    const c = () => {
      this.localStorage.setItem('br.namekey', n);
      this.localStorage.setItem('br.namekeyname', o);
      this.localStorage.setItem('br.name', o);
      this.localStorage.removeItem('br.nameaddr');
    };
    const s = async (name: string, key: string) => {
      try {
        const res = await this.fetch('/api/name?name=' + encodeURIComponent(name), { headers: { 'X-Name-Key': key } });
        if (!res.ok) return null;
        const j = await res.json();
        return !(!j || j.mine !== true);
      } catch {
        return null;
      }
    };
    const i = await s(o, n);
    return a
      ? i === null ? e('unknown', o, a)
        : i === false ? e('refused', o, a)
        : a.toLowerCase() === o.toLowerCase() ? (c(), e('taken', o, a))
        : (await s(a, r)) !== false ? e('kept', o, a)
        : (c(), e('taken', o, a))
      : i === false ? e('refused', o)
      : (c(), e(i === null ? 'unknown' : 'taken', o));
  }
  syncPairWords(t: string) {
    const e = this.SYNC.nameLast || { name: '', have: '' };
    const a = e.name || 'the name';
    const n = 'paired — your chat rooms are the same on both devices';
    const o = e.have && e.have.toLowerCase() !== (e.name || '').toLowerCase() ? e.have : '';
    switch (t) {
      case 'taken': return n + ', and the name ' + a + ' is yours here too ✓' + (o ? ' — it replaces ' + o + ', whose key the box no longer honoured' : '');
      case 'same': return n + '; this device already had the name ' + a + ' ✓';
      case 'kept': return n + '. This device keeps its own name ' + o + "; the other device's name " + a + ' stays there';
      case 'refused': return n + ', but the name ' + a + ' did NOT come along: the device the code came from holds an old key for it. /dm jae there to free the name, reserve it again there, then pair once more';
      case 'unknown': return n + '; the name ' + a + ' could not be checked with the box just now — it is checked again within two minutes';
      default: return n + '. The other device holds no reserved name, so none came along';
    }
  }
  syncMerge(t: { rooms?: SiteRoom[]; left?: Record<string, number>; name?: { name?: string; key?: string } }) {
    this.SYNC.nameP = this.syncNameIn(t.name);
    const e: Record<string, number> = { ...this.SYNC.left };
    for (const [a, n] of Object.entries(t.left || {})) if (ROOMRE.test(a)) e[a] = Math.max(e[a] || 0, Number(n) || 0);
    const a = new Map<string, SiteRoom>();
    for (const x of [...this.roomsKnown(), ...(Array.isArray(t.rooms) ? t.rooms : [])]) {
      if (!x || !ROOMRE.test(x.id)) continue;
      const had = a.get(x.id);
      if (had) {
        if ((Number(x.at) || 0) > had.at) {
          had.at = Number(x.at) || 0;
          had.name = String(x.name || had.name).slice(0, 40);
        }
        if (!had.key && x.key) had.key = String(x.key);
      } else a.set(x.id, { id: x.id, name: String(x.name || 'private room').slice(0, 40), key: String(x.key || ''), at: Number(x.at) || 0 });
    }
    const n = [...a.values()].filter((x) => !(e[x.id] > x.at)).sort((x, y) => y.at - x.at);
    this.SYNC.left = e;
    this.localStorage.setItem('br.syncleft', JSON.stringify(e));
    this.roomsSave(n);
  }
  async syncPull() {
    if (!this.SYNC.key) return false;
    try {
      const t = await this.fetch('/api/sync/' + this.SYNC.id);
      if (t.status === 404) {
        this.SYNC.v = 0;
        return true;
      }
      if (!t.ok) return false;
      this.SYNC.v = Number(t.headers.get('ETag')) || 0;
      this.syncMerge(await this.syncOpen(syncUnb64((await t.text()).trim())));
      await this.SYNC.nameP;
      return true;
    } catch {
      return false;
    }
  }
  async syncPush() {
    if (!this.SYNC.key || this.SYNC.pushing) return;
    this.SYNC.pushing = true;
    try {
      for (let i = 0; i < 3; i++) {
        const t = await this.syncSeal({ rooms: this.roomsKnown(), left: this.SYNC.left, name: this.syncNameOut(), at: Date.now() });
        const e = await this.fetch('/api/sync/' + this.SYNC.id, { method: 'PUT', headers: { 'If-Match': String(this.SYNC.v), 'Content-Type': 'text/plain' }, body: syncB64(t) });
        if (e.ok) {
          this.SYNC.v = Number(e.headers.get('ETag')) || this.SYNC.v + 1;
          return;
        }
        if (e.status !== 412) return;
        await this.syncPull();
      }
    } catch {
      // as the site: the next change tries again
    } finally {
      this.SYNC.pushing = false;
    }
  }
  async syncCodeKey(t: string) {
    const e = await crypto.subtle.importKey('raw', new TextEncoder().encode(t), 'PBKDF2', false, ['deriveKey']);
    return crypto.subtle.deriveKey(
      { name: 'PBKDF2', salt: new TextEncoder().encode('bubblerumble rooms ' + t), iterations: 2e5, hash: 'SHA-256' },
      e, { name: 'AES-GCM', length: 256 }, false, ['encrypt', 'decrypt'],
    );
  }
  async syncStart() {
    await this.syncUse(crypto.getRandomValues(new Uint8Array(32)), true);
  }
  async syncOffer() {
    if (this.SYNC.key) await this.syncPush();
    else await this.syncStart();
    const t = unhex(this.localStorage.getItem('br.synckey')!);
    for (let i = 0; i < 3; i++) {
      const e = [...crypto.getRandomValues(new Uint8Array(6))].map((x) => SYNCCODE[x % 31]).join('');
      const a = await this.syncCodeKey(e);
      const n = crypto.getRandomValues(new Uint8Array(12));
      const o = new Uint8Array(await crypto.subtle.encrypt({ name: 'AES-GCM', iv: n }, a, t));
      const r = new Uint8Array(12 + o.length);
      r.set(n);
      r.set(o, 12);
      const c = await this.fetch('/api/sync/pair', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ code: e, blob: syncB64(r) }) });
      if (c.ok) return e;
      if (c.status !== 409) {
        const j = await c.json().catch(() => ({}));
        throw new Error(j.error || 'could not make a code (' + c.status + ')');
      }
    }
    throw new Error('could not make a code');
  }
  async syncAccept(t: string) {
    if ((t = t.toUpperCase().replace(/[^A-Z2-9]/g, '')).length !== 6) throw new Error('a code is six letters and digits');
    const e = await this.fetch('/api/sync/pair/' + t);
    const a = await e.json().catch(() => ({}));
    if (!e.ok) throw new Error(a.error || 'no such code');
    const n = syncUnb64(a.blob);
    const o = await this.syncCodeKey(t);
    let r: Uint8Array;
    try {
      r = new Uint8Array(await crypto.subtle.decrypt({ name: 'AES-GCM', iv: n.slice(0, 12) }, o, n.slice(12)));
    } catch {
      throw new Error('that code did not open the key');
    }
    if (r.length !== 32) throw new Error('that code did not open the key');
    await this.syncUse(r, true);
    let c = 'none';
    try {
      c = await (this.SYNC.nameP || Promise.resolve('none'));
    } catch {
      // as the site: no outcome reads as none
    }
    return this.syncPairWords(c);
  }
}
```

```js
import { SiteBrowser } from './site-sync.ts';

const [cmd, code] = process.argv.slice(2);

const name = process.env.NAME ?? 'browsie';
if (!(cmd === 'offer' || (cmd === 'accept' && code))) {
  console.error('usage: npm run fake-browser -- offer | accept <code>');

const b = new SiteBrowser(server);
const key = randomBytes(16).toString('hex');

  method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ name, key, addr: `g1${'q'.repeat(38)}` }),

else console.log(await b.syncAccept(code));

// what this browser holds, each time it changes, for ten minutes
let last = '';
const show = () => {
  const now = JSON.stringify({ name: b.chatReservedName(), rooms: b.roomsKnown().map((r) => `${r.name}${r.key ? ' 🔑' : ''}`) });
  if (now !== last) console.log((last = now));
};
show();
const end = Date.now() + 600_000;
while (Date.now() < end) {
  await new Promise((r) => setTimeout(r, 5000));
  await b.syncPull();
  show();
}
```
